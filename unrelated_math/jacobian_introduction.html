Introduction to the Jacobian

Let's start from the beginning. The Jacobian is actually not a particularly complicated idea. It's a way of organizing partial derivatives into a matrix. The interesting part is that this matrix lets us extend the ordinary chain rule to functions of several variables.

I'll build this up gradually, using examples, and then connect it to Problem 24.

1. Start with the ordinary derivative

In single-variable calculus, if we have

\[f(x)=x^2\]

we take the derivative:

\[f'(x)=2x\]

This derivative tells us how the output changes when we change the input.

For a small change \(\Delta x\),

\[\Delta f\approx f'(x)\Delta x\]

For example, at \(x=3\), the derivative is 6. Increasing \(x\) by 0.01 increases \(f\) by approximately 0.06.

The derivative measures how sensitive the output is to changes in the input.

2. What if a function has two inputs?

Suppose

\[f(x,y)=x^2+3y\]

Now the function has two inputs, \(x\) and \(y\), but still only one output.

We can measure how the function changes when either input changes:

\[\frac{\partial f}{\partial x}=2x\]
\[\frac{\partial f}{\partial y}=3\]

We already know how to combine these into a gradient:

\[\nabla f(x,y)=(2x,3)\]

The Jacobian contains exactly the same information, but it's written as a row matrix:

\[\boxed{Df(x,y)=\begin{bmatrix}2x&3\end{bmatrix}}\]

Notice that it's a \(1\times2\) matrix:

  • One row, because we have one output.
  • Two columns, because we have two inputs.

So for a scalar-valued function, the Jacobian is just the transpose of the gradient (when the gradient is written as a column vector).

3. What if a function has two inputs AND two outputs?

This is where the Jacobian becomes more interesting.

Suppose we have

\[G(x,y)=(x^2+y,xy)\]

This function takes a point \((x,y)\) and returns another point with two coordinates.

Let's name the outputs:

\[\begin{aligned}u(x,y)&=x^2+y\\v(x,y)&=xy\end{aligned}\]

We want to know how each output changes in response to each input.

That gives us four partial derivatives:

\[\begin{aligned}u_x&=2x&\qquad u_y&=1\\v_x&=y&\qquad v_y&=x\end{aligned}\]

The Jacobian organizes these four derivatives into a matrix:

\[\boxed{DG(x,y)=\begin{bmatrix}u_x&u_y\\v_x&v_y\end{bmatrix}=\begin{bmatrix}2x&1\\y&x\end{bmatrix}}\]

The organization is important:

  • Rows correspond to outputs.
  • Columns correspond to inputs.

Here is the structure visually:

This works for any number of inputs or outputs.

In general:

\[\boxed{\text{Jacobian dimensions}=(\text{number of outputs})\times(\text{number of inputs})}\]
FunctionJacobian size
\(\mathbb R\to\mathbb R\)\(1\times1\)
\(\mathbb R^2\to\mathbb R\)\(1\times2\)
\(\mathbb R^2\to\mathbb R^2\)\(2\times2\)
\(\mathbb R^2\to\mathbb R^3\)\(3\times2\)
\(\mathbb R^3\to\mathbb R^2\)\(2\times3\)

4. What does the Jacobian actually mean?

This is the part I think is worth understanding, rather than simply memorizing how to fill in a matrix.

Remember how the ordinary derivative tells us that

\[\Delta f\approx f'(x)\Delta x\]

The Jacobian does the same thing, but for several inputs and outputs.

For our example,

\[G(x,y)=(x^2+y,xy)\]

we have

\[DG(x,y)=\begin{bmatrix}2x&1\\y&x\end{bmatrix}\]

Suppose we are at \((x,y)=(2,3)\). Then

\[DG(2,3)=\begin{bmatrix}4&1\\3&2\end{bmatrix}\]

Now suppose we change the inputs by small amounts \(\Delta x,\Delta y\).

We can estimate the change in the two outputs by multiplying:

\[\boxed{\begin{bmatrix}\Delta u\\\Delta v\end{bmatrix}\approx\begin{bmatrix}4&1\\3&2\end{bmatrix}\begin{bmatrix}\Delta x\\\Delta y\end{bmatrix}}\]

Multiplying out gives

\[\Delta u\approx4\Delta x+\Delta y\]
\[\Delta v\approx3\Delta x+2\Delta y\]

This tells us how changes in the inputs produce changes in the outputs.

The Jacobian is the multivariable version of the derivative: it provides the best linear approximation to how a function changes near a point.

That's also why it's useful for linearization, which we've already worked with.

5. The Jacobian and the multivariable chain rule

Now we're ready for the important application in Problem 24.

Remember the ordinary chain rule:

\[\frac{d}{dx}f(g(x))=f'(g(x))g'(x)\]

We take the derivative of the outer function, evaluate it at the inner function, and multiply by the derivative of the inner function.

The multivariable chain rule works exactly the same way, except that we multiply Jacobian matrices instead of ordinary derivatives.

Suppose

\[g:\mathbb R^2\to\mathbb R^2\]

and

\[f:\mathbb R^2\to\mathbb R\]

We compose them:

\[h=f\circ g\]

That is,

\[h(x,y)=f(g(x,y))\]

The Jacobian chain rule says

\[\boxed{Dh(x,y)=Df(g(x,y))\,Dg(x,y)}\]

Let's see what that means.

Write the inner function as

\[g(x,y)=(u(x,y),v(x,y))\]

The Jacobian of \(f\) is

\[Df(u,v)=\begin{bmatrix}f_u&f_v\end{bmatrix}\]

The Jacobian of \(g\) is

\[Dg(x,y)=\begin{bmatrix}u_x&u_y\\v_x&v_y\end{bmatrix}\]

Multiply:

\[Dh(x,y)=\begin{bmatrix}f_u&f_v\end{bmatrix}\begin{bmatrix}u_x&u_y\\v_x&v_y\end{bmatrix}\]

The result is

\[\boxed{Dh(x,y)=\begin{bmatrix}f_uu_x+f_vv_x&f_uu_y+f_vv_y\end{bmatrix}}\]

Notice that this is just the expanded multivariable chain rule:

\[\frac{\partial h}{\partial x}=\frac{\partial f}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial f}{\partial v}\frac{\partial v}{\partial x}\]
\[\frac{\partial h}{\partial y}=\frac{\partial f}{\partial u}\frac{\partial u}{\partial y}+\frac{\partial f}{\partial v}\frac{\partial v}{\partial y}\]

The Jacobian matrix multiplication is simply a convenient way to perform these calculations.

One detail to remember: the derivatives \(f_u,f_v\) are evaluated at \((u,v)=g(x,y)\).

6. Connecting this to Problem 24

Here's the problem you were given:

\[f(u,v)=ve^u\]
\[g(x,y)=(2xy,x+y)\]

Notice how the functions fit together:

\[\mathbb R^2\xrightarrow{\;g\;}\mathbb R^2\xrightarrow{\;f\;}\mathbb R\]

So:

  • Part (a) asks for \(Df\), a \(1\times2\) matrix.
  • Part (b) asks for \(Dg\), a \(2\times2\) matrix.
  • Part (c) asks for \(Dh\), which we obtain by multiplying those matrices in the correct order.

The dimensions work perfectly:

\[\underbrace{Dh}_{1\times2}=\underbrace{Df(g(x,y))}_{1\times2}\underbrace{Dg(x,y)}_{2\times2}\]

And importantly, we are not taking a determinant here. We're calculating and multiplying Jacobian matrices.

7. Jacobian matrix versus Jacobian determinant

One final distinction, because the terminology can be confusing.

The Jacobian matrix is the matrix of first partial derivatives:

\[DG=\begin{bmatrix}u_x&u_y\\v_x&v_y\end{bmatrix}\]

The Jacobian determinant is the determinant of that matrix:

\[\det DG=u_xv_y-u_yv_x\]

The determinant is particularly useful in change-of-variables problems involving double integrals, where it measures local area scaling.

In Problem 24, you're being asked for the Jacobian derivative, meaning the matrix, not its determinant.

What to remember

There are really only three essential ideas:

  1. The Jacobian is a matrix containing all first partial derivatives, with one row per output and one column per input.
  2. The Jacobian tells us how small changes in the inputs affect the outputs, just as an ordinary derivative does.
  3. The multivariable chain rule is matrix multiplication:
\[\boxed{D(f\circ g)(x,y)=Df(g(x,y))Dg(x,y)}\]

Now I'd suggest tackling just part (a) of Problem 24. We have \(f(u,v)=ve^u\). All we need to do is take its two partial derivatives and put them into a \(1\times2\) matrix. That will be our first application of the Jacobian.
