The Two Uses of the Gradient

The gradient always points in the direction of steepest increase and is perpendicular to level curves or level surfaces. The difference is which function we're taking the gradient of.

1. Explicit function: z = f(x, y)

∇f = ⟨fx, fy⟩

This is a 2D vector that:

  • Points in the direction of steepest increase of z in the xy-plane.
  • Is perpendicular to the level curves f(x, y) = c.

2. Implicit function: F(x, y, z) = 0

∇F = ⟨Fx, Fy, Fz⟩

This is a 3D vector that:

  • Is perpendicular to the level surface F(x, y, z) = 0.
  • Can be used to find the tangent plane.

Example: z = x² + y²

To find the direction of steepest increase:

f(x, y) = x² + y²

∇f(1, 0) = ⟨2, 0⟩

This points in the positive x-direction, where height increases fastest.

To find a normal vector to the surface:

Rewrite the same equation implicitly:

F(x, y, z) = x² + y² − z = 0

∇F(1, 0, 1) = ⟨2, 0, −1⟩

This vector is perpendicular to the surface and can be used to find its tangent plane.

Key distinction: ∇f describes steepest increase of height in the xy-plane. ∇F is perpendicular to the 3D surface. They're gradients of different functions.
