In your MVP packetSection 4.8H · Main task · Problems 1–4 · pp. 36–37

From a row of quantities to a total cost

The packet continues the food-order example from Section 4.7H. The order matrix has rows for soccer and drama, and columns for chips, cookies, and drinks:

\[Q=\begin{bmatrix}8&7&4\\10&4&4\end{bmatrix}\]

The price matrix uses those same food items as its rows, and Mainstreet and Grandpa’s as its columns. The prices are dollars per package of chips, per dozen cookies, and per gallon of drink:

\[P=\begin{bmatrix}2.50&2.00\\3.00&4.00\\2.00&1.50\end{bmatrix}\]

Worked example 1 — Find one entry of the cost matrix

Original problem — Main 1: Find the four entries a, b, c, and d in the total-cost matrix. Start with a, the soccer order’s cost at Mainstreet.

Worked solution: Use the soccer row from Q and the Mainstreet column from P. Multiply each quantity by its matching unit price, then add:

Food itemQuantityMainstreet unit priceCost
Chips8$2.50$20.00
Cookies7$3.00$21.00
Drinks4$2.00$8.00
\[\begin{aligned}a&=8(2.5)+7(3)+4(2)\\&=20+21+8\\&=49\end{aligned}\]

This is matrix multiplication: each entry of the product comes from one row of the first matrix and one column of the second. Multiply the matching entries and add those products.

Row × column, then add

To find the entry in row i, column j of \(QP\), use row i of Q and column j of P. This is different from addition, which combines entries in the same position.

The result has event rows and store columns. For Main 2, explain that you choose an event’s row and a store’s column, multiply matching quantities and prices, and add. Repeat for each event/store combination.

When can two matrices be multiplied?

A row from the first matrix and a column from the second must have the same number of entries. Therefore, the number of columns in the first matrix must equal the number of rows in the second.

\[(2\times\underbrace{3}_{\text{must match}})(\underbrace{3}_{\text{must match}}\times2)\longrightarrow2\times2\]

The product takes its row count from the first matrix and its column count from the second. Here two events multiplied by two stores produce a \(2\times2\) result. Keep Q first and P second: their categories are arranged to match quantities with prices.

Worked example 2 — Add more events

Original problem — Main 3: Can the five-event order matrix be multiplied by the original price matrix? If so, find the costs.

Worked solution: Yes. The order matrix is \(5\times3\), and the price matrix is \(3\times2\). The three food categories match, so the result is \(5\times2\).

For example, chess at Mainstreet costs \(3(2.50)+4(3.00)+2(2.00)=23.50\). Repeating the same procedure gives:

More food categories require more price rows — Main 4

No: the new order matrix is \(5\times5\), but the old price matrix is \(3\times2\). The inner dimensions do not match. The order includes rolls and cold cuts, whose prices are missing. Add a price row for each new item to make a \(5\times2\) price matrix; then the product would have five event rows and two store columns.

4. Go — Triangle patterns

In your MVP packetSection 4.8H · Go · Problems 13–17 · p. 40

Use the figure in your packet. Let n be the step number. Count carefully at steps 1, 2, and 3, then describe how each quantity changes before checking the key.

Counting convention — Go 16

The question does not specify which angles to count. The key counts the 60° corners of every unit triangle, including the white triangles. It does not count only the three outside corners of the large triangle.

Check your work — Go 13–17 answer key

For 14, count both blue and white unit triangles. The formulas use positive integer step numbers n.

Problem / quantitySteps 1, 2, 3Rule
13 — Width1, 2, 3\(n\)
14 — Unit triangles1, 4, 9\(n^2\)
15 — Perimeter3, 6, 9\(3n\)
16 — 60° unit-triangle corners3, 12, 27\(3n^2\)
17 — White triangles0, 1, 3\(\frac{n(n-1)}2\)

Each side of the large triangle has length n, so its perimeter is 3n. Each unit triangle has three 60° corners.

For 17, each horizontal row has one more blue triangle than white triangle. There are n rows and \(n^2\) unit triangles in total. Remove the n extra blue triangles, then split the remaining count equally between blue and white: \(\frac{n^2-n}{2}=\frac{n(n-1)}2\).
