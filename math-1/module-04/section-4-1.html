Revisit the ideas from class

This section explains some of the ideas you explored in class through the guided exercises. Use it alongside the “A Develop Understanding Task” portion of Section 4.1 in your MVP packet.

In your MVP packetSection 4.1 · Main task · pp. 1–2 · Problems 1–3

Use the cafeteria actions to understand and justify the steps in solving an equation.

What does it mean to solve an equation?

An equation states that two expressions are equal. A solution is a value that makes the equation true when substituted for the variable. For example, 5 is a solution of \(3x+2=17\), because \(3(5)+2=17\).

Solving means finding the value or values that make the statement true. We do this by writing simpler equivalent equations—equations with the same solutions—until the unknown value is clear.

Keep both sides equal

You may add or subtract the same number on both sides, or multiply or divide both sides by the same nonzero number. These steps preserve the solutions because each step can be reversed.

For instance, from \(3x+2=17\), subtract 2 from both sides to get \(3x=15\). Then divide both sides by 3 to get \(x=5\). Subtracting 2 from only one side would change the equation.

Worked example 1 — How many trays were in each carton?

In your MVP packetSection 4.1 · Main 1 · p. 1

In the packet, Elvira unloads 4 cartons, students take 24 trays, and the remaining trays are divided equally among 3 serving lines. Each line ends up with 12 trays. Let \(x\) be the number of trays in each carton.

ActionNumber of trays
Unload 4 cartons\(4x\)
24 trays are taken\(4x-24\)
Divide the remaining trays among 3 lines\(\frac{4x-24}{3}\) per line

Since each line has 12 trays, the equation is

\[\frac{4x-24}{3}=12\]

Inverse operations undo one another: adding undoes subtracting, and multiplying undoes dividing. Here the last action was dividing by 3. Undo that first, then undo subtracting 24, then multiplying by 4.

StepEquivalent equationMeaning in the story
Multiply both sides by 3\(4x-24=36\)There were 36 trays before they were split among the lines.
Add 24 to both sides\(4x=60\)There were 60 trays before students took 24.
Divide both sides by 4\(x=15\)Each carton contained 15 trays.

Check: \(\frac{4(15)-24}{3}=\frac{36}{3}=12\). The answer fits both the equation and the story.

Worked example 2 — Why the order of actions matters

In your MVP packetSection 4.1 · Main 2 · pp. 1–2

The Post-It notes describe doubling the number of students, adding 4 students, and leaving one-third of the group at the table. In the order printed, the final number is 12:

\[\frac{2x+4}{3}=12\]

Undo the actions in reverse order: multiply both sides by 3, subtract 4 from both sides, and divide both sides by 2.

\[\begin{aligned}\frac{2x+4}{3}&=12\\2x+4&=36\\2x&=32\\x&=16\end{aligned}\]

There were 16 students initially. Checking the actions gives \(16\to32\to36\to12\).

Now add 4 before doubling. This gives \(\frac{2(x+4)}{3}=12\). Undo division by 3, then multiplication by 2, then addition of 4:

\[\begin{aligned}\frac{2(x+4)}{3}&=12\\2(x+4)&=36\\x+4&=18\\x&=14\end{aligned}\]

This time, the starting number is 14 students. The actions give \(14\to18\to36\to12\). Both stories end at 12, but they begin with different numbers. The operation order changes the equation and can change its solution.

Read the structure before choosing a step

In your MVP packetSection 4.1 · Main 3 · p. 2

Parentheses and fraction bars show which operations apply to a whole group. In \(\frac{2(x+4)}{3}\), addition of 4 comes before doubling. In \(\frac{2x+4}{3}\), doubling comes before addition of 4. In both, division by 3 is last.

Worked example 3 — A different final operation

Original equation from Main 3: \(2\left(\frac{x}{3}+4\right)=12\)

The actions are: divide the starting number by 3, add 4, then double. Undo the final doubling first:

\[\begin{aligned}2\left(\frac{x}{3}+4\right)&=12\\\frac{x}{3}+4&=6\\\frac{x}{3}&=2\\x&=6\end{aligned}\]

The steps divide both sides by 2, subtract 4 from both sides, and multiply both sides by 3. Checking gives \(6\to2\to6\to12\).

The first note always describes the unknown starting group, and the last note says 12 remain. The order of the three middle notes is:

Equation, in packet orderMiddle three actionsStarting students
\(\frac{2(x+4)}{3}=12\)Add 4 → double → divide by 3\(x=14\)
\(2\left(\frac{x}{3}+4\right)=12\)Divide by 3 → add 4 → double\(x=6\)
\(\frac{2x+4}{3}=12\)Double → add 4 → divide by 3\(x=16\)

Choose a step by what it undoes. You can also rewrite an expression using distribution, as in Set below. Whatever method you use, each new equation must have the same solutions as the previous one.

3. Set — Equivalent expressions and equations

In your MVP packetSection 4.1 · Set · p. 4 · Problems 7–15

Equivalent expressions have the same value for every value of the variable. Rewriting an expression does not change its value, so it can also be used within an equation without changing its solutions.

Use parentheses and fraction bars carefully

The distributive property multiplies each term in a group: \(a(b+c)=ab+ac\). A minus sign before parentheses subtracts every term in the group. Set 7 compares \(14-(3a+2)\) with \(14-3a-2\); they are equivalent because both the \(3a\) and the 2 are subtracted.

Likewise, dividing a sum or difference by a number divides every term. Set 9 uses

\[\frac{x-7}{4}=\frac{x}{4}-\frac74\]

In Set 10, that same reasoning gives

\[\frac{3(w-9)}5=\frac{3w-27}5=\frac{3w}5-\frac{27}5\]

The final term is \(-\frac{27}5\), not \(-27\). The fraction bar applies to both terms in the numerator.

Start by clearing the denominator

The earlier problems ask you to rewrite expressions, so splitting a fraction into separate terms can be useful there. When solving an equation, it is often easier to multiply both sides by the denominator first. This removes the fraction before you do the rest of the arithmetic.

Worked example 4 — Clear the denominator before solving

Original problem — Set 13: Solve \(\frac{4(x-2)}5=20\).

Worked solution: Multiply both sides by 5, then divide by 4 and add 2:

\[\begin{aligned}\frac{4(x-2)}5&=20\\4(x-2)&=100\\x-2&=25\\x&=27\end{aligned}\]

There is no need to distribute the 4 or divide each term in the numerator by 5.

Worked example 5 — Keep the numerator together

Original problem — Set 15: Solve \(\frac{4x-2}5=20\).

Worked solution: Multiply both sides by 5, then add 2 and divide by 4:

\[\begin{aligned}\frac{4x-2}5&=20\\4x-2&=100\\4x&=102\\x&=\frac{102}4=\frac{51}2=25.5\end{aligned}\]

Compare the two examples: \(4(x-2)\) and \(4x-2\) are different expressions, so the equations have different solutions.

In Set 14, \(4(\frac{x}5-2)=20\), dividing both sides by 4 first is also convenient. Choose steps that simplify the equation; you do not have to split a fraction into separate terms.

Study the examples, then try Set independently before checking the key.
