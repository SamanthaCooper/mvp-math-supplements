Solving for a variable in a formula

A formula is an equation describing a relationship between quantities. A literal equation contains more than one variable. To solve for a particular variable, rearrange the equation so that variable is alone on one side. The answer will usually be an expression containing the other variables.

Use the same operations as in Section 4.1: do the same thing to both sides to keep them equal. Letters stand for numbers, so you can add or subtract a variable, or multiply or divide by it. A quantity you divide by must be nonzero.

Keep track of the quantity you want

When solving for \(S\), isolate \(S\); treat the other quantities as given. You do not need their numerical values to rearrange the formula.

What do the quantities measure?

Elvira’s variables describe lunch counts, prices, and serving time. Use these meanings throughout the main task:

SymbolMeaningUnits
\(S\), \(W\), \(P\)Students buying salad, sandwich, and pizza lunches, respectivelyStudents
\(F\)Food serversServers
\(C\)Classes in the schoolClasses
\(M_T\)Time to serve all studentsMinutes
\(P_L\)Price per lunchDollars per lunch

The subscript distinguishes a variable: \(P_L\) is the price per lunch, while \(P\) counts pizza customers. \(P_L\) is one variable, not \(P\) multiplied by \(L\).

Units help you interpret an expression. Add or subtract quantities measured in the same units. Dividing a student count by a class count gives students per class. Multiplying dollars per lunch by the number of lunches gives dollars.

Worked example 1 — Recover the salad-line count

Original formula — Main 1–3: \(A=\frac{S+W+P}{C}\)

\(A\) is the average number of lunch-buying students per class. To solve for \(S\), multiply both sides by the denominator \(C\) first, then subtract \(W\) and \(P\):

\[\begin{aligned}A&=\frac{S+W+P}{C}\\AC&=S+W+P\\S&=AC-W-P\end{aligned}\]

This makes sense: \(AC\) is the total number of students buying lunch. Removing the sandwich and pizza customers leaves the salad customers.

Worked example 2 — Find the price per lunch

Original formula — Main 4–6: \(R=P_L(S+W+P)\)

\(R\) is total lunch revenue, measured in dollars. Divide both sides by the total number of lunches:

\[\begin{aligned}\frac{R}{S+W+P}&=P_L\\P_L&=\frac{R}{S+W+P}\end{aligned}\]

The result is dollars per lunch: total revenue divided by the number of lunches sold.

In Main 7, \(T=S+W+P\) names the total number of students buying lunch. It lets us write the revenue equation more simply as \(R=P_LT\).

When the variable you want is in the denominator

Worked example 3 — Recover the total student count

Original formula — Main 9: \(M=\frac{M_T}{T}\)

\(M\) is the average serving time per student, in minutes per student. To solve for \(T\), multiply both sides by \(T\) to remove the denominator, then divide by \(M\):

\[\begin{aligned}M&=\frac{M_T}{T}\\MT&=M_T\\T&=\frac{M_T}{M}\end{aligned}\]

Total serving time divided by minutes per student gives the number of students.

In Main 8, \(D_F=\frac{T\cdot P_L}{F}\) is the average lunch revenue per food server, in dollars per server. Multiply both sides by \(F\), then divide by \(T\), to obtain \(P_L=\frac{D_FF}{T}\).

Writing a rate from its units

Main 10(a) asks for average students served each minute. Put students in the numerator and minutes in the denominator: \(\frac{T}{M_T}\). Compare this with \(M=\frac{M_T}{T}\), which measures minutes per student. Reversing the fraction changes the meaning.

Packet clarification — Main 10(b) · p. 7

The question asks for “the average number of minutes students wait in the pizza line.” It is unclear whether this means time per student or the total time for the pizza students. The likely intention is to use the average serving time per student, \(M=\frac{M_T}{T}\), assuming similar serving times for the different lunch options.

Per pizza student: \(\frac{M_T}{T}=M\) minutes per student

Total for the pizza students: \(P\frac{M_T}{T}=PM\) minutes of serving time

“Serving time” would be clearer than “waiting time.” The question should also specify which of these two quantities is wanted.

Describe a set using a rule

A set is a collection of values. You can describe a small set by listing its members, such as \(\{1,2,3\}\). But you cannot list every real number in an interval: there are infinitely many. Set-builder notation describes a set by giving a rule for which values belong to it.

How to read set-builder notation
\[\{x\mid x\in\mathbb R,\ 0\le x<5\}\]

Read this as: “The set of all real numbers \(x\) such that \(x\) is greater than or equal to 0 and less than 5.”

Part of the notationMeaning
\(\{\ \}\)Braces enclose the description of a set.
\(x\)The first \(x\) names the values in the set. The conditions after the bar tell us which values to include.
\(\mid\)The vertical bar means “such that.”
\(x\in\mathbb R\)\(\in\) means “is a member of,” and \(\mathbb R\) is the set of real numbers—all numbers on the number line, including negative numbers, fractions, and decimals.
\(0\le x<5\)Include values greater than or equal to 0 and less than 5. The comma before this condition means that it must also be satisfied.

Worked example — Which values belong?

For \(\{x\mid x\in\mathbb R,\ 0\le x<5\}\):

  • 0 belongs because \(0\le x\) includes 0.
  • 2 and 1.5 both belong: each is greater than or equal to 0 and less than 5.
  • 5 does not belong because \(x<5\) excludes 5.
  • −1 does not belong because it is less than 0.

This is the same set as the interval \([0,5)\): the square bracket includes 0, and the parenthesis excludes 5. Both notations describe all the real numbers between the endpoints, not just whole numbers.

Move between set-builder and interval notation

To convert to interval notation, identify the lower and upper bounds and whether each is included. To convert back, write those same bounds as an inequality inside braces, with \(x\in\mathbb R\). For example:

\[[-4,7]=\{x\mid x\in\mathbb R,\ -4\le x\le7\}\]

Both endpoints are included, so both notations use inclusive symbols. For more on interval notation, see Section 3.2.

On a number line, use a filled circle for an included endpoint and an open circle for an excluded one. Shade the values that satisfy the inequality. Try the exercises before opening the key.
