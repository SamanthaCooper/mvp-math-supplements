What is a matrix?

A matrix is a rectangular arrangement of numbers in rows and columns, usually enclosed in brackets. Each number is an entry. Rows go across; columns go down. Its dimensions give the number of rows first, then the number of columns: a \(2\times3\) matrix has two rows and three columns.

In Main 1, you are asked to organize Elvira’s Post-It notes from three years. Choose a consistent order so the same position always means the same thing. Here we use soccer first and drama second, with chips, cookies, and drinks in that order.

EventChips (packages)Cookies (dozens)Drinks (gallons)
Soccer1064
Drama835

The blue notes, from three years ago, can therefore be written as this matrix:

\[B=\begin{bmatrix}10&6&4\\8&3&5\end{bmatrix}\]

For example, the entry in row 2, column 3 is 5: the drama club’s order was 5 gallons of drinks. Keep the row order, column order, and units the same for every year. The brackets contain the numbers; the labels tell us what they mean.

Main 1 answers: With that same arrangement, the yellow notes (two years ago) and pink notes (last year) give:

\[Y=\begin{bmatrix}6&7&4\\12&5&3\end{bmatrix}\]
\[P=\begin{bmatrix}8&8&4\\10&4&4\end{bmatrix}\]

Worked example 1 — Average the three years’ orders

Original problem — Main 2: Use the average amount ordered over the past three years to recommend this year’s order for each event, and explain how you calculated it.

Worked solution: Add the three values for each event and food item, then divide by 3. For soccer chips:

\[\frac{10+6+8}{3}=8\]

Matrix addition adds entries in the same position. The matrices must have the same dimensions; here their labels and units also match.

Write the three matrices side by side, keeping each event in the same row and each food item in the same column:

\[B+Y+P=\begin{bmatrix}10&6&4\\8&3&5\end{bmatrix}+\begin{bmatrix}6&7&4\\12&5&3\end{bmatrix}+\begin{bmatrix}8&8&4\\10&4&4\end{bmatrix}\]

Add the entries that occupy the same position in all three matrices. For example, the top-left entries give soccer chips: \(10+6+8\). The bottom-right entries give drama drinks: \(5+3+4\). Do this for all six positions:

\[B+Y+P=\begin{bmatrix}10+6+8&6+7+8&4+4+4\\8+12+10&3+5+4&5+3+4\end{bmatrix}=\begin{bmatrix}24&21&12\\30&12&12\end{bmatrix}\]

To average the orders, divide every entry of this sum by 3:

\[A=\frac13(B+Y+P)=\begin{bmatrix}8&7&4\\10&4&4\end{bmatrix}\]

Multiplying a matrix by a single number means multiplying every entry by that number. This is called scalar multiplication; the scalar is the number. Here the scalar is \(\frac13\).

For future years, keep the categories aligned, add the corresponding entries, and divide by the number of years included.

Worked example 2 — Include three guests per member

Original problem — Main 3: Each team or club member can bring three guests. Assuming each guest consumes about the same amount as the member, use your Main 2 order to find the new order.

Worked solution: Each member is now part of a group of four people: the member plus three guests. Multiply every entry of the average-order matrix by 4:

\[4A=4\begin{bmatrix}8&7&4\\10&4&4\end{bmatrix}=\begin{bmatrix}32&28&16\\40&16&16\end{bmatrix}\]

The soccer order becomes 32 packages of chips, 28 dozen cookies, and 16 gallons of drinks. The drama order becomes 40 packages, 16 dozen, and 16 gallons.

Teacher’s review of the source packet

Missing definition — Set heading, p. 34: Apart from the table of contents, this is the first use of “matrix” or “matrices” in the Math I student packets. The main task asks students to organize information but does not name or define a matrix; Set then uses “Organizing information in matrices” without an explanation. Before students begin Set, explicitly define a matrix, its rows, columns, entries, and dimensions, and show how a labeled table becomes a matrix. The in-class explanation above supplies this missing introduction.

Ready’s heading says “Creating tables from graphs,” although the exercises supply rules and equations. Go 14’s fractional bacteria values are better labeled as population estimates. No substantial calculation errors were identified.
