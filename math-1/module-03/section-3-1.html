Turn a real situation into a graph

In your MVP packetSection 3.1 · Main task · p. 1 · Problem 1

Learn to label the axes and show changes in water level as you prepare to sketch Sylvia’s pool graph.

A graph can show how one quantity depends on another. In a pool story, the independent variable is elapsed time: it belongs on the horizontal (x) axis. The dependent variable is the height of the water: it belongs on the vertical (y) axis. One point, such as , means at 4 minutes, the water was 2 feet high.

As you move from left to right along a graph, focus on the direction and steepness:

A complete example: Sylvia’s pool

In your MVP packetSection 3.1 · Main task · p. 1 · Problems 1–2

See one possible graph for all six activities and practice telling the story it represents.

Sylvia must empty the pool, clean it, and refill it. The original packet lists six activities: use one bucket; drain with a hose; use three buckets with friends; clean the empty pool; take a break; and refill with a hose. We can choose a sensible order because the packet does not prescribe one. Cleaning must happen after emptying and before final refilling.

Example assumptions: The MVP task gives no exact times or water depths. Suppose the pool has vertical sides, starts 4 feet deep, and the height changes steadily during each removal or filling interval. The values below describe one possible situation, not measurements supplied by the packet.

Worked example 1 — Tell the story from the graph.

“Sylvia began with four feet of water. During the first two minutes, the water level decreased slowly while she used one bucket. For the next two minutes the level decreased more quickly because three people used buckets. She then drained the rest with a hose until the pool was empty at eight minutes. The level remained constant at zero while she cleaned and took a break. At thirteen minutes she started refilling; the level increased steadily until the pool reached four feet at twenty-one minutes.”

Why this water-height graph is a function

In your MVP packetSection 3.1 · Main task · p. 1 · Problem 3

Explain why each moment in time has exactly one water height.

A function assigns exactly one output to each input. At any single instant, the pool has one water height, so water height is a function of time. The same water height can occur at many different times; that does not break the rule.

Changing the times or the order of the activities can give a different valid graph. It will still represent a function: each time corresponds to exactly one water height.

Add a few points to understand the curve.

Three points meet the packet’s instruction, but extra points can help you sketch an exponential curve. Keep using the same rule, k(x) = 4 · 2x.

For negative inputs, \(2^{-1}=\frac12\) and \(2^{-2}=\frac14\). Thus \(k(-1)=4\cdot\frac12=2\) and \(k(-2)=4\cdot\frac14=1\). Add the points (−1, 2) and (−2, 1). Each step left halves the output: \(4,2,1,\frac12\), and so on. This helps show why the curve approaches zero while staying above the x-axis.

To the right, k(3) = 4 · 8 = 32. Add (3, 32) to see how quickly the curve rises. Draw a smooth curve through the points rather than connecting them with straight segments.

Before you finish: label your axis scales and check that your three points satisfy the equation. For large exponential outputs, smaller or negative inputs can make the graph easier to draw.

Compare graph characteristics

In your MVP packetSection 3.1 · SET · p. 4 · Problems 12–13

Compare direction, steepness, and whether each graph is connected or has breaks.

A straight-line graph is linear and has a constant rate of change. A curved graph is nonlinear, and its steepness may change as you move along it. For Problem 12, both graphs decrease, but the straight line maintains the same steepness while the curve does not.

For Problem 13: the horizontal marks are segments containing intervals of inputs. The graph has breaks, so describe it as discontinuous. This differs from a discrete graph, which includes only separate input values, usually shown as isolated points.

The domain is the set of allowed inputs; the range is the set of outputs. Look at the horizontal and vertical values each graph includes when comparing them.

Original problem — Go 20: Find the value of \(x\) that makes \(10=2^x-22\) true.

Worked solution: Add 22 to both sides:

\[32=2^x\]

Since \(2^5=32\), the solution is \(x=5\).

Check: \(2^5-22=32-22=10\)

Teacher’s review of the source packet

Section 3.1, Set, descriptions (c) and (d) — Clarify the time window

The gasoline description should identify the period between completed deliveries. The watermelon description should specify time throughout one Thursday, rather than a count recorded each Thursday. The wording clarification in the Set section makes these intended time windows explicit.

Section 3.1, Set, Problem 13 — Discontinuous versus discrete

The upper graph uses separated horizontal segments. These segments contain intervals of inputs, so they should not be reinterpreted as isolated points. The useful classroom comparison is a connected linear graph versus a discontinuous graph with constant pieces.

This connects to the distinction raised in Module 2: whole-number outputs do not by themselves make a domain discrete. Counts can change in steps over time. Keep the allowed inputs separate from whether the graph has breaks or jumps.
