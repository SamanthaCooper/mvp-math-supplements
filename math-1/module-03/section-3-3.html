1. In class: A Practice Understanding Task

Revisit the ideas from class

This section explains some of the ideas you explored in class through the guided exercises. Use it alongside the “A Practice Understanding Task” portion of Section 3.3 in your MVP packet.

In your MVP packetSection 3.3 · Main task · pp. 11–13 · Problems 1–16

Use these reminders as you describe the graphs, tables, and situations.

Does it represent a function?

Each input must have exactly one output. On a graph, use the vertical line test: no vertical line should meet more than one included point. Repeated outputs are fine; two different outputs for the same input are not. Open circles are not included.

Read the features

Domain: the x-values represented. Range: the y-values reached. Filled endpoints are included; open endpoints are excluded. For separated dots, list individual values in braces rather than filling the spaces with an interval.

Worked example 1 — Domain and range of separate points

Problem: The graph below consists of just three points. Find its domain and range.

Solution: The x-values are −2, 0, and 3, so the domain is \(\{-2,0,3\}\). The y-values are 1 and 4, so the range is \(\{1,4\}\). List 4 only once, even though two points have that output.

An interval includes every real number between its endpoints. So \([-2,3]\) would include inputs such as 1, 2, and 1.3, none of which belong to this graph. Even if every integer from −2 to 3 were included, we would still need to list those integers in braces; the interval would incorrectly include the fractional values between them. Likewise, \([1,4]\) would include outputs such as 2.5, but this graph’s only outputs are 1 and 4.

An x-intercept is a point where a graph meets the x-axis, so its y-coordinate is zero. A y-intercept is a point where a graph meets the y-axis, so its x-coordinate is zero. Write intercepts as ordered pairs.

A function is increasing where it rises from left to right, decreasing where it falls, and constant where it stays level. Describe these using intervals of x-values.

A relative maximum or minimum is a local peak or valley. An overall maximum or minimum is the greatest or least output on the entire graph. Give both the output and the input where it occurs.

Symmetry and end behavior

A graph has symmetry when a reflection or rotation makes it match its original position. For y-axis symmetry, the left and right sides are mirror images: folding the picture along the y-axis would make them line up.

For x-axis symmetry, the upper and lower parts are mirror images across the x-axis. For origin symmetry, turning the graph halfway around the origin makes it match itself.

End behavior: describe what happens at the left and right ends—whether the graph rises, falls, or approaches a height.

2. Ready — Find intersections using tables

In your MVP packetSection 3.3 · Ready · p. 14 · Problems 1–4

Try Ready 1–4 yourself first, then use the answer key below to check your intersection points.

The intersection of two graphs has the same input and the same output in both functions. A pair of value tables locates it when both functions give matching outputs for one listed x-value. Comparing outputs from different rows does not locate an intersection.

3. Set — Evaluate claims about linear and exponential functions

In your MVP packetSection 3.3 · Set · p. 15 · Problems 5–10

Use examples and counterexamples to assess linear, exponential, and sequence claims.

Try the problems yourself first.

Decide whether each statement is true or false, and write your explanation before opening the answer key. Use the answers below to check your work. If your answer differs, compare the reasoning and revise your explanation.

A claim about all functions of a type must hold in every case. One counterexample is enough to show that it is false.

Check your work — Set 5–10 answer key

5. All linear functions are increasing.

False. A line increases when its slope is positive, decreases when its slope is negative, and is constant when its slope is zero. For example, \(y=-x+4\) decreases.

6. Arithmetic sequences are an example of linear functions.

True. An arithmetic sequence adds the same amount each time its index increases by 1. Its points lie on a straight line. For example, \(a(n)=5+2(n-1)\) gives \(5,7,9,\ldots\) for \(n=1,2,3,\ldots\). The domain consists of the sequence’s term numbers, so its graph is separate points on that line.

7. Exponential functions have a domain that includes all real numbers.

True for the unrestricted exponential functions used here, such as \(y=2^x\). Positive, zero, negative, and fractional inputs are all allowed. For example, \(2^0=1\) and \(2^{-1}=\frac12\).

8. Geometric sequences have a domain that includes all integers.

False. The inputs are the sequence’s term numbers, usually \(1,2,3,\ldots\), or sometimes \(0,1,2,\ldots\). Negative integers are not included in these sequences. A sequence and a continuous exponential function can have similar formulas but different domains.

9. The range for an exponential function includes all real numbers.

False. For example, \(y=2^x\) has only positive outputs, so its range is \((0,\infty)\). It never gives zero or a negative number. This single example disproves the claim.

10. All linear relationships are functions with a domain and range containing all real numbers.

False. A vertical line such as \(x=2\) is a linear relationship but is not a function of x: the same x-value has many y-values. Also, a horizontal line such as \(y=5\) is a function, but its range is only \(\{5\}\). A nonconstant function \(y=mx+b\) with unrestricted inputs does have all real numbers in its domain and range.
