1. Does the relationship represent a function?

In your MVP packetSection 3.3 · Main task · pp. 11–12 · Problems 1–9

Decide whether a graph or table assigns one output to each input.

A function gives exactly one output for each input in its domain. To check a plotted relationship, imagine a vertical line moving across the graph. If it meets two or more included points at the same x-value, that input has more than one output, so the relationship is not a function. This is the vertical line test.

Worked example 1 — Repeated inputs versus repeated outputs

The points \((-2,4)\), \((0,1)\), and \((3,4)\) represent a function. Each input has one output. The output 4 appearing twice is fine: two different inputs can give the same output.

Adding the point \((0,5)\) would make the relationship fail the test. Input 0 would now have two outputs, 1 and 5. A vertical line at \(x=0\) would meet both included points.

A curve can fail the test even if it is connected and smooth. A sideways curve with an upper and a lower branch can assign two y-values to the same x-value. Likewise, a collection of separate dots can fail if two dots are vertically aligned. Look for those patterns in Main task 2 and 5.

An open circle is not an included point. If one piece has an open circle at a particular x-value and another piece has a filled point at that same x-value, only the filled point supplies the output. Use that distinction in Main task 7.

2. Read a graph’s features

In your MVP packetSection 3.3 · Main task · pp. 11–12 · Problems 1–7

Identify intercepts, domain, range, direction, and relative or overall extreme values.

The domain is the set of x-values represented; the range is the set of y-values reached. Read the domain horizontally and the range vertically, using filled and open endpoints to decide whether a boundary is included. For separated dots, list individual values in braces rather than filling the spaces with an interval.

An x-intercept has output zero; a y-intercept has input zero. A graph may have several x-intercepts or none. Write each intercept as an ordered pair, and look for points where the graph touches an axis as well as points where it crosses.

A function is increasing where it rises from left to right, decreasing where it falls, and constant where it stays level. Give these as intervals of inputs. A decreasing function can remain above zero; direction and the sign of the output are different features.

Relative and overall maximums and minimums

A relative maximum is an output higher than the nearby outputs: a local peak. A relative minimum is an output lower than the nearby outputs: a local valley. An overall maximum or overall minimum compares the output with the entire graph, not just its neighbors. A local peak need not be the highest point on the graph.

Worked example 2 — A local peak that is not the overall maximum

This original graph consists of straight segments connecting the four labeled, included points.

  1. Domain and range: the inputs run from −4 to 5, so the domain is \([-4,5]\). The lowest output is −1 and the highest is 4, so the range is \([-1,4]\).
  2. Direction: increasing on \((-4,-1)\) and \((2,5)\), decreasing on \((-1,2)\).
  3. Relative extremes: the peak at \((-1,3)\) gives a relative maximum of 3. The valley at \((2,0)\) gives a relative minimum of 0.
  4. Overall extremes: the maximum is 4 at \(x=5\), and the minimum is −1 at \(x=-4\). The local peak and valley are not the overall extremes.

Intercepts. The middle segment falls one unit per step right and passes through \((-1,3)\), so it reaches \((0,2)\): the y-intercept. It touches the x-axis at \((2,0)\). The first segment rises 4 units over 3 input units. Starting at \((-4,-1)\), a rise of 1 takes \(\frac34\) of an input unit, giving the other x-intercept \((-\frac{13}{4},0)\).

For curved graphs, use the same ideas: locate peaks, valleys, and endpoints, then compare their heights. Coordinates read from an unlabeled curve may be approximate. You do not need the curve’s formula to describe its visible features.

3. Symmetry and end behavior

In your MVP packetSection 3.3 · Main task · pp. 11–12 · Problems 1–7

Describe symmetry and what happens at the ends of each graph.

A graph has symmetry about the y-axis if its left and right sides mirror each other. Whenever \((a,b)\) is on the graph, \((-a,b)\) is too. For example, \(y=x^2\) contains both \((2,4)\) and \((-2,4)\); folding its graph along the y-axis matches the two sides.

A graph has symmetry about the origin if a half-turn around the origin matches it to itself. A point \((a,b)\) pairs with \((-a,-b)\). The line \(y=2x\), for instance, contains both \((3,6)\) and \((-3,-6)\). A shifted line such as \(y=2x+1\) does not have that origin symmetry.

Symmetry about the x-axis pairs \((a,b)\) with \((a,-b)\). An upper-and-lower sideways curve can have this symmetry while failing the vertical line test. Symmetry by itself does not establish that a relationship is a function.

End behavior describes what happens toward the left and right ends of a graph. For an arrowed graph that continues, follow each end: does its output grow without bound, fall without bound, or approach a height? For a graph with finite endpoints, describe where it begins and ends.

Worked example 3 — Describe two familiar continuing graphs

For the line \(y=-2x+3\), moving right makes the output smaller and smaller; moving left makes it larger and larger. In notation:

\[\begin{aligned}x\to\infty&:\ y\to-\infty,\\x\to-\infty&:\ y\to\infty.\end{aligned}\]

The arrows in this notation mean “heads toward.” For \(y=2^x\), the graph grows without bound to the right. To the left, outputs such as \(\frac12,\frac14,\frac18\) get closer to zero while remaining positive. It approaches the x-axis rather than crossing it.

On Main task 4’s decreasing dots, describe the trend among the plotted inputs. On Main task 6’s line, use its continuing direction. On graphs with filled endpoints, include those endpoints when finding the overall greatest or least output.

4. Features from tables and real situations

In your MVP packetSection 3.3 · Main task · pp. 12–13 · Problems 8–14

Interpret features from continuous and discrete tables, sequences, daylight, payments, and filling.

Continuous relationships versus discrete lists

A table for a continuous relationship shows selected points from a graph that includes intermediate inputs and outputs. A discrete function, such as a sequence indexed by term number, is defined at separate input values. Its graph consists of separate points.

Worked example 4 — Three discrete observations

A function is defined only at \((1,6)\), \((2,2)\), and \((3,5)\). Its domain is \(\{1,2,3\}\) and range is \(\{2,5,6\}\). Its minimum value is 2 at input 2; its maximum is 6 at input 1.

It has no x-intercept because none of its outputs is zero, and no y-intercept because input zero is not in the domain. The range is not \([2,6]\): values such as 4 are not supplied by this discrete function.

In Main task 8, use the stated continuous domain \([0,6]\) and read the table’s overall pattern. In Main task 9, list the five separate input values and their outputs in braces. For either table, find the minimum by locating the smallest output, then report the input where it occurs.

Use the situation to choose the inputs and endpoints

In a filling problem, time can include fractional minutes. In a payment schedule or sequence, the number of completed steps is a whole number. Stop the domain when the situation stops—for example, when the tank is full or the balance is paid.

Worked example 5 — A tank with a physical endpoint

An empty 12-gallon tank fills at 3 gallons per minute until it is full. The output is gallons in the tank and the input is elapsed time. After t minutes, \(V(t)=3t\).

The tank fills in \(12\div3=4\) minutes. During filling, the domain is \([0,4]\) minutes and the range is \([0,12]\) gallons. The function increases throughout, has a minimum of 0 at the start and a maximum of 12 at the end, and has both intercepts at \((0,0)\).

Worked example 6 — A balance after each payment

A $360 balance is reduced by $30 each week, with no interest. Let w be the number of completed payments, beginning with \(w=0\). Then \(B(w)=360-30w\).

It takes \(360\div30=12\) payments to reach zero. The domain is \(\{0,1,2,\ldots,12\}\), and the range is \(\{360,330,300,\ldots,0\}\). The balance decreases from a maximum of $360 to a minimum of $0. Its intercepts are \((0,360)\) and \((12,0)\).

These are values after each payment, so plot separate points rather than a continuous diagonal line. This is the same type of model used for the weekly payments in Main task 12.

“Half of” and “one-half less than” are different rules

Worked example 7 — Compare two sequences

Starting at 24, taking half of each preceding term gives \(24,12,6,3,\ldots\). The multiplier is \(\frac12\), so this is geometric:

\[a(n)=24\left(\tfrac12\right)^{n-1}.\]

Starting at 24, taking one-half less than the preceding term means subtracting \(\frac12\): \(24,23.5,23,22.5,\ldots\). This is arithmetic:

\[b(n)=24-\tfrac12(n-1).\]

For both rules, \(n=1,2,3,\ldots\).

Both decrease, but the geometric sequence stays positive and approaches zero, while the arithmetic sequence eventually reaches zero and becomes negative. In the geometric example the maximum is 24 at the first term and there is no minimum. In the arithmetic example the maximum is also 24, and the continued subtraction gives no minimum.

For daylight by month (Main task 10), use month numbers 1 through 12 as the inputs. Daylight follows a seasonal pattern: longer in summer and shorter in winter. Identify the months with the greatest and least daylight rather than assuming a steady increase all year.

5. Features of linear and exponential equations

In your MVP packetSection 3.3 · Main task · p. 13 · Problems 15–16

Sketch a restricted linear function and an exponential function and describe their features.

To sketch an equation, calculate a few convenient points and use the known shape: a straight line for a linear rule and a smooth curve for a continuous exponential rule. Apply any stated domain restriction before describing the graph.

Worked example 8 — A line restricted to nonnegative inputs

Sketch \(f(x)=-3x+6\) for \(x\ge0\). The points \((0,6)\), \((1,3)\), and \((2,0)\) lie on the line. Draw a filled starting point at \((0,6)\), then continue the straight line downward to the right.

The domain is \([0,\infty)\); the range is \((-\infty,6]\). The y-intercept is \((0,6)\), and the x-intercept is \((2,0)\). It decreases throughout its domain, has an overall maximum of 6 at 0, and has no minimum because its output keeps decreasing.

The restriction changes the graph’s features: extending the line to the left would give outputs larger than 6, but those negative inputs are excluded here.

Worked example 9 — An unrestricted exponential graph

Sketch \(g(x)=2^x\). Useful points are \((-1,\frac12)\), \((0,1)\), \((1,2)\), and \((2,4)\). Draw a smooth increasing curve through them.

The domain is \((-\infty,\infty)\), and the range is \((0,\infty)\). Its y-intercept is \((0,1)\); it has no x-intercept. There is no maximum and no minimum. To the left it approaches zero; to the right it grows without bound.

The value zero is not included in the range. A curve approaching zero is different from reaching zero.

6. Ready — Find intersections using tables

In your MVP packetSection 3.3 · Ready · p. 14 · Problems 1–4

Fill value tables and find matching outputs at the same input.

The intersection of two graphs has the same input and the same output in both functions. A pair of value tables locates it when both functions give matching outputs for one listed x-value. Comparing outputs from different rows does not locate an intersection.

7. Set — Evaluate claims about linear and exponential functions

In your MVP packetSection 3.3 · Set · p. 15 · Problems 5–10

Use examples and counterexamples to assess linear, exponential, and sequence claims.

A statement about all functions of a type must hold in every case. One counterexample is enough to show that it is false. Give the reason, not just the word “false.”

Linear direction depends on slope

For \(y=mx+b\), positive m gives an increasing line, negative m a decreasing line, and zero m a constant line. Thus “all linear functions increase” fails: \(y=-x+4\) is a decreasing example.

A nonconstant line with unrestricted real inputs has domain and range \((-\infty,\infty)\). A horizontal line such as \(y=5\) has the same unrestricted domain but range \(\{5\}\). A vertical line such as \(x=2\) is a linear relationship, but it is not a function of x because that one input has many outputs.

Sequences keep separate integer inputs

An arithmetic sequence follows a linear rule: equal increases of 1 in its index give equal output changes. For example, \(a(n)=5+2(n-1)\) gives \(5,7,9,\ldots\) for \(n=1,2,3,\ldots\). Its plotted points lie on a line, but its domain is those separate term indices, not every real number.

A geometric sequence uses a multiplying rule, such as \(b(n)=5\cdot2^{n-1}\). Its inputs are also term indices. A sequence beginning at 1 does not include zero or negative indices, so “all integers” is too broad a description of its domain.

Continuous exponential curves include fractional inputs

The standard unrestricted exponential function \(y=b^x\), with \(b>0\) and \(b\ne1\), has domain \((-\infty,\infty)\) and positive range \((0,\infty)\). It increases when \(b>1\) and decreases when \(0<b<1\). Its domain and range are not the same set.

The continuous curve \(y=2^x\) includes inputs like \(x=\frac12\) and \(x=-1\). A geometric sequence indexed from 1 includes only its specified whole-number indices. This is why the exponential function and a geometric sequence can use similar formulas while having different domains.

8. Go — Read the domain from a graph

In your MVP packetSection 3.3 · Go · p. 15 · Problems 11–14

Read each graph’s domain and write it in interval notation.

To find a domain, ask: which x-values have a point on this graph? Follow each piece horizontally. A filled endpoint includes its x-value; an open endpoint excludes it; an arrow continues the interval in that direction. Gaps between pieces stay out of the domain.

Use brackets for included finite boundaries and parentheses for excluded boundaries. Infinity always takes a parenthesis. Join separate input intervals with \(\cup\), meaning “union.” The heights of the endpoints do not go into the domain.

Additional Go problem A — A ray with an open endpoint

Problem. A graph follows \(y=2x+1\), has an open endpoint at \((3,7)\), and continues indefinitely to the lower left. State its domain in interval notation.

  1. The graph continues to the left without an input boundary, giving \(-\infty\) as the left side.
  2. The rightmost input is 3, but its endpoint is open, so 3 is excluded.
  3. Therefore the domain is \(\boxed{(-\infty,3)}\).
  4. Check sample inputs: \(x=2\) is included and gives \(y=5\). Input 3 is excluded, even though the line’s formula would give 7 there. Input 4 is outside the graph.

The upper boundary is 3, the endpoint’s x-coordinate, not 7, its y-coordinate.

Additional Go problem B — Three pieces with different endpoint types

Problem. Find the domain of the original graph below. The first two pieces are finite segments; the third begins at an open point and continues to the right.

  1. The first piece runs from included input −5 to excluded input −2: \([-5,-2)\).
  2. The second includes every input from 0 through 3: \([0,3]\).
  3. The third starts after 4 and continues right: \((4,\infty)\).
  4. Combine the pieces: \(\boxed{[-5,-2)\cup[0,3]\cup(4,\infty)}\).

Check the boundaries. Input −5 is included, −2 is excluded, 0 and 3 are included, and 4 is excluded. Input 5 belongs to the ray. Inputs such as −1 and 3.5 fall in gaps and are excluded.

Apply the same steps to Go 11’s separate pieces, Go 12’s two-way line, Go 13’s open-ended ray, and Go 14’s curve with an open starting point. Do not let a curve’s rising or falling direction distract you from its horizontal extent.
