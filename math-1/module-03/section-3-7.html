1. In class: A Practice Understanding Task

Revisit the ideas from class

This section explains some of the ideas you explored in class through the guided exercises. Use it alongside the “A Practice Understanding Task” portion of Section 3.7 in your MVP packet.

In your MVP packetSection 3.7 · Main task · pp. 34–35 · Problems 1–15

Identify the input and output, then decide whether the relationship is a function.

Start with the input

The independent variable is the input; the dependent variable is the output. A function assigns exactly one output to each input in its domain. Ask: Could the same input give two different outputs? If so, the relationship is not a function.

Reading “A versus B” or “A with respect to B”

The usual graphing convention is:

  • B is the input — horizontal axis.
  • A is the output — vertical axis.

Main Problem 3 — Cost of gas versus amount pumped

In your MVP packetSection 3.7 · Main 3 · p. 34

In the MVP packet, you are asked about this relationship: “The cost of gas versus the amount of gas pumped.”

The amount pumped is the input; the cost is the output. Think of choosing an amount of gas and then finding what it costs. At a fixed price per gallon, each amount determines exactly one cost, so the relationship is a function.

For a refresher on checking graphs and reading their domain and range, see the function test and graph features in Section 3.3.

Repeated outputs are allowed

Different inputs can have the same output. In Main 8, the inputs 3 and 5 both lead to 5, while 7 leads to 9. Each input still has just one output, so this is a function. Likewise, several percentage scores can produce the same letter grade under a fixed grading scale.

Worked example — Check the table’s inputs

In your MVP packetSection 3.7 · Main 6 · p. 34

The left column gives the inputs (distance); the right column gives the outputs (days). Distance 6 appears twice, paired with both 2 days and 5 days. Because the same input has two different outputs, this relation is not a function.

Does the input give enough information?

For a circle, each radius determines one area, and each area determines one radius. For water in a fixed cylinder, each water height determines one volume. Each of these relationships is a function in the stated direction.

Worked example — The same area can need different amounts of fence

In your MVP packetSection 3.7 · Main 12 · p. 35

Original problem: “The length of fence needed with respect to the amount of rectangular area to be enclosed.”

Solution: Treat area as the input and fence length as the output. Both rectangles below enclose 12 square units:

Side lengthsAreaFence length (perimeter)
3 and 4\(3\cdot4=12\)\(2(3+4)=14\)
2 and 6\(2\cdot6=12\)\(2(2+6)=16\)

The same area gives two different fence lengths, so area alone does not determine the perimeter. This relationship is not a function of area unless another condition fixes the rectangle’s shape.

The function test also applies to rules

Main 13’s sequence gives one term for each term number: \(f(1)=3\) and \(f(n+1)=f(n)+4\). Its explicit rule is \(f(n)=3+4(n-1)\), for integers \(n\ge1\). The input is the term number and the output is the term’s value.

In Main 14, a rational number can be written as a ratio of two integers with a nonzero denominator; an irrational number cannot. The rule gives output 1 to rational inputs and 0 to irrational inputs. Every real number falls into exactly one category, so every input has exactly one output. It is a function even though its outputs do not form a continuous curve.

The same test works for the other situations in the packet: choose the input, identify the output, and justify whether that input determines one output.

3. Set — Functions in context

In your MVP packetSection 3.7 · Set · p. 37 · Problems 9–13

State the input and output before describing domain and range. These situations do not supply enough measurements to give exact numerical endpoints; describe the relevant times, heights, values, names, or outcomes instead. Try each problem yourself, then check your reasoning below.

Check your work — Set 9–13 answer key

  1. Input: time during one Ferris wheel ride. Output: the rider’s height above the ground.

    Domain: the times during the ride. Range: heights from the lowest to the highest position reached, including both.

    Function: yes. At each time, the rider has one height; returning to the same height at different times is allowed.

  2. Input: date during a specified calendar year at a fixed location. Output: that day’s number of daylight hours.

    Domain: the dates in that year. Range: the daylight durations for those dates; numerical extremes depend on the location.

    Function: yes. Each date has one daylight duration at that location.

  3. Input: time from the car’s purchase in 1978 to the chosen present date. Output: its value.

    Domain: that time interval. Range: the car values over that interval, which are not provided.

    Function: yes, when using one value for this car at each time. Its value need not always decrease; a collectible car can appreciate.

  4. Input: a name. Output: a corresponding phone number.

    Domain: the names considered. Range: the corresponding phone numbers.

    Function: not in general. The same name can correspond to several phone numbers.

  5. Taking stadium as the input and game outcome as the output:

    Domain: stadiums where the player plays. Range: the observed outcomes, such as wins, losses, and ties if permitted.

    Function: not in general. Games played at the same stadium can have different outcomes.
