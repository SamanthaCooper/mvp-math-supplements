In your MVP packetSection 5.3 · Main task · Problems 1–6 · pp. 10–11

Two forms, the same line

Carlos writes the space boundary as \(y=-\frac14x+15\). Clarita writes it as \(6x+24y=360\). Both describe exactly the same combinations of cats \(x\) and dogs \(y\) that use all 360 square feet.

FormGeneral formSpace-boundary example
Slope-intercept form\(y=mx+b\)\(y=-\frac14x+15\)
Standard form\(Ax+By=C\)\(6x+24y=360\)

In slope-intercept form, \(m\) is the slope and \(b\) is the y-intercept’s y-coordinate. Standard form keeps the two variable terms on the same side.

Main 1(a) — Solve for y

EquationOperation
\(6x+24y=360\)Original equation
\(24y=360-6x\)Subtract \(6x\) from both sides
\(y=15-\frac14x\)Divide both sides by 24
\(y=-\frac14x+15\)Reorder the terms

Main 1(b) — Return to standard form

EquationOperation
\(y=-\frac14x+15\)Original equation
\(24y=-6x+360\)Multiply both sides by 24 to clear the fraction
\(6x+24y=360\)Add \(6x\) to both sides

Main 2–4 — Write the budget boundary both ways

Carlos can use points such as \((0,16)\), \((5,14)\), and \((10,12)\). Each increase of 5 cats replaces 2 dogs, giving slope \(-\frac25\) and y-intercept \(16\). His equation is \(y=-\frac25x+16\). Clarita uses the cost per pet to write \(32x+80y=1280\).

Main 3: standard to slope-interceptOperation
\(32x+80y=1280\)Original equation
\(80y=1280-32x\)Subtract \(32x\) from both sides
\(y=-\frac25x+16\)Divide both sides by 80
Main 4: slope-intercept to standardOperation
\(y=-\frac25x+16\)Original equation
\(80y=-32x+1280\)Multiply both sides by 80
\(32x+80y=1280\)Add \(32x\) to both sides

Main 5–6 — Use intercepts to draw the line

An x-intercept is a point where the graph meets the x-axis, so its y-coordinate is zero. A y-intercept is a point where the graph meets the y-axis, so its x-coordinate is zero.

Carlos can substitute \(x=0\) and \(x=60\) into \(y=-\frac14x+15\) to obtain \((0,15)\) and \((60,0)\). These easy, well-separated points give an accurate line.

Clarita can get the same points directly from standard form:

Set one coordinate to zeroSolveIntercept
\(x=0\)\(24y=360\;\Rightarrow\;y=15\)\((0,15)\)
\(y=0\)\(6x=360\;\Rightarrow\;x=60\)\((60,0)\)

Plot both points and draw the straight line through them. Setting each coordinate to zero is often the simplest way to graph a line given in standard form.

The budget boundary works the same way: its intercepts are \((0,16)\) and \((40,0)\).
