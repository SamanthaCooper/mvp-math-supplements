Try the packet task on your own first

Write and graph both constraints before reading the worked solutions. Then use these explanations to check your reasoning.

In your MVP packet

Section 5.4 · Main task · Feeding Time and Pampering Time · p. 14

Keep the units consistent

Let \(x\) be the number of cats and \(y\) the number of dogs. Each person's limit is \(8\cdot60=480\) minutes per day. Use daily totals: feeding takes 12 minutes per cat and 20 minutes per dog, while pampering takes 16 minutes per cat and 20 minutes per dog.

“Up to” includes exactly 480 minutes, so use \(\le\). Counts of animals must be nonnegative whole numbers. The shaded region shows the inequality for real coordinates; only points with whole-number coordinates represent actual pet counts.

Feeding Time — worked solution

Original problem: Write and graph the feeding-time constraint from the packet.

Worked solution: Total daily feeding time is \(12x+20y\) minutes.

\[12x+20y\le480\]

Equivalently,

\[ y\le-\frac35x+24.\]

The boundary \(12x+20y=480\) has intercepts \((40,0)\) and \((0,24)\): all cats or all dogs, respectively. Draw a solid line because equality is allowed. For each fixed number of cats, the allowed dog counts are on or below the line.

Check the side using \((0,0)\): \(0\le480\) is true, so shade the side containing the origin.

Pampering Time — worked solution

Original problem: Write and graph the pampering-time constraint from the packet.

Worked solution: Clarita's daily time limit gives

\[16x+20y\le480\]

Equivalently,

\[ y\le-\frac45x+24.\]

The boundary intercepts are \((30,0)\) and \((0,24)\). Use a solid line and shade on and below it in the first quadrant. The origin again satisfies the inequality.

Check what a point means

For example, 20 cats and 8 dogs require \(12(20)+20(8)=400\) feeding minutes and \(16(20)+20(8)=480\) pampering minutes. That combination meets both time limits, using all of Clarita's time. Each graph above displays its own time constraint, as requested in this task.

2. Ready — Change equation forms

In your MVP packet

Section 5.4 · Ready · Problems 1–9 · p. 15

For slope-intercept form \(y=mx+b\), isolate \(y\). For standard form \(Ax+By=C\), move the variable terms to the same side and clear fractions. For a refresher on equivalent operations, see Math I 4.1.

Packet error — Ready directions for 4–9

The directions say \(A,B,C\) are “whole numbers,” but some of these equations require negative coefficients or constants. Use integers instead, with \(A>0\). For example, \(y=7x-3\) becomes \(7x-y=3\), so \(B=-1\).

Ready 8 — clear a fraction first

Original problem: Rewrite \(y=\frac35x-2\) in standard form.

Worked solution: Multiply both sides by 5, then rearrange.

\[5y=3x-10\]\[3x-5y=10.\]

Try the remaining conversions before opening the checking key.

Check your work — Ready 1–9
  1. \(y=\frac12x+4\)
  2. \(y=-4x-3\)
  3. \(y=-\frac53x+5\)
  4. \(7x-y=3\)
  5. \(2x-y=-9\)
  6. \(4x+y=-11\)
  7. \(x-2y=-16\)
  8. \(3x-5y=10\)
  9. \(x+6y=4\)

Equivalent integer multiples are also valid if the coefficient of \(x\) is positive.

3. Set — Model Ben's writing exam

In your MVP packet

Section 5.4 · Set · Problem 10(a–b) · p. 15

Here \(x\) counts poems and \(y\) counts paragraphs. “At least” gives a lower bound for the total number of items; the two-hour exam gives an upper bound for writing time. Convert the hours to minutes before combining the times.

Write both inequalities and draw each on its own grid before checking.

Check your work — Set 10(a–b)

10(a) — Inequalities

Number of items:

\[x+y\ge10.\]

Time:

\[30x+10y\le120\]

Equivalently,

\[3x+y\le12.\]

In context, \(x,y\) are nonnegative whole numbers.

10(b) — Separate graphs

Plot not shown. For the item-count constraint, draw a solid line through \((10,0)\) and \((0,10)\); shade on and above \(y=10-x\) in the first quadrant. For the time constraint, draw a solid line through \((4,0)\) and \((0,12)\); shade on and below \(y=12-3x\) in the first quadrant.

The origin fails the item-count inequality (\(0\ge10\) is false) but satisfies the time inequality (\(0\le120\) is true). This checks both shading directions.

4. Go — Check a value and solve equations

In your MVP packet

Section 5.4 · Go · Problems 11–20 · p. 16

For 11–16, replace every \(h\) with 3 and ask whether the resulting statement is true. Preserve parentheses: \(3(h-4)\) means three times the entire difference.

For 17–20, solve for \(x\). Distribute before collecting terms. If the variable terms cancel, a false statement means no solution; a true statement means every real value works. Try the exercises before checking below.

Check your work — Go 11–20

Is \(h=3\) a solution?

  1. Yes: \(3(3-4)=-3\).
  2. Yes: \(3(3)=2(3+2)-1=9\).
  3. No: \(2(3)-3=3\), while \(3+6=9\).
  4. Yes: \(9>-3\).
  5. Yes: \(\frac35\le3\cdot\frac15=\frac35\); equality is allowed.
  6. Yes: \(\frac35>3\cdot\frac16=\frac12\).

Solve for \(x\)

  1. \(x=\frac52\)
  2. \(x=\frac53\), since \(3(x+5)=20\) gives \(x+5=\frac{20}{3}\).
  3. No solution: subtracting \(2x\) from \(2x+3=2x-5\) gives the false statement \(3=-5\).
  4. All real numbers: \(4(6x-1)=3(8x+5)-19\) simplifies to \(24x-4=24x-4\), true for every real \(x\).
