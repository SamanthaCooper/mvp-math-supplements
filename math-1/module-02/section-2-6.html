A useful clarification — Ready, Problem 8

To find the y-intercept from an equation, set x = 0. You may have learned to read the y-intercept directly from slope-intercept form, y = mx + b. That works because setting x = 0 makes the mx term zero, leaving y = b. Reading b is just a shortcut for the substitution.

For an exponential equation, y = a · rx, do exactly the same thing: set x = 0. Since r0 = 1 for a positive base, the result is y = a. The procedure is identical; the equations simplify differently.

Choose efficiently

Linear: starting value at x=0 and slope → slope-intercept; another known point and slope → point-slope; initial term and stepwise difference → recursive if you need only the next few terms. Exponential: starting value and multiplier → explicit; first known term and common ratio → either recursive or shifted explicit, depending on the question. For a far-away term, explicit form avoids applying the recursion many times.

These are the forms in the packet's toolbox, not five unrelated kinds of mathematics. A linear sequence is arithmetic when restricted to consecutive integer inputs; an exponential sequence is geometric when restricted to consecutive integer inputs.

3. GO — Solve one-step equations and justify each step

IN YOUR MVP PACKETGo · printed p. 43 · Problems 15–20
Use the additive and multiplicative properties of equality to solve equations. Justify the operation and simplification, not just the final answer.

A solution is a number that makes an equation true. To keep an equation balanced, apply the same operation to both sides.

Properties of equality

Additive property: If A = B, then A + c = B + c. Subtracting c is adding −c. Multiplicative property: If A = B, then cA = cB for any c; to undo multiplication by a nonzero number, multiply both sides by its reciprocal. Identities: A + 0 = A and 1 · A = A.

The goal is to isolate the variable by undoing the operation attached to it. State the property applied, then perform the arithmetic, and finally substitute the answer to check.

Teacher's Review of the Original MVP Packet

Overall: Section 2.6 is a useful consolidation lesson. Unlike many discovery-based tasks, it names the forms directly and asks students to explain why a chosen form is efficient. The teacher guide explicitly supports comparing different valid methods.

Where a short clarification would help

Domain classifications: For main task Problems 4–5 and the exponential graph in Problem 7, the packet sometimes asks for or implies a continuous/discrete classification without stating the permitted input domain. Population is counted in whole people but time may be continuous; a plant's height changes between weekly observations; an equation such as can be given a real or integer domain. Specify the intended model or accept a justified domain choice. This is a modeling clarification, not an indication that the equations are wrong.

Minor navigation issue: Two consecutive main-task problems are both numbered 3. Refer to them as the “geometric sequence Problem 3” and the “graphed-line Problem 3.”

The remainder of the packet is mathematically coherent. Set targets efficient representation; Go explicitly teaches equality properties and asks students to justify their use.
