Identify the pattern of change

IN YOUR MVP PACKETSection 2.3 · Main task · pp. 13–18 · Problems 1–16
Identify each type of function and give two pieces of mathematical evidence. Begin with how the output changes as the input changes.

In Sections 2.1–2.2 you worked with arithmetic sequences, geometric sequences, and their related functions. Today's task is to recognize those patterns regardless of how they are presented.

Key meanings

Linear: equal changes in the input produce equal differences in the output. For input steps of size 1, the output adds the same number each step.

Exponential: equal changes in the input produce equal multiplication factors in the output. For input steps of size 1, the output multiplies by the same positive factor each step in the standard real-valued exponential model.

Neither: the relationship does not follow either pattern. "Not linear" does not automatically mean "exponential."

Packet clarification — Main task, Problem 14

“Each point on the graph is exactly 1/3 of the previous point” is not precise: a point has two coordinates and cannot simply be “one-third” of the preceding point in the sense intended here. The likely intended statement is: when the input increases by one unit, each new output is one-third of the previous output. With that assumption the outputs follow an exponential (geometric) pattern. Without equal input steps, this classification is not determined.

Packet clarification — Main task, Problem 9

A finite table of height and shoe-size measurements can show that the listed observations do not lie on a single linear or exponential pattern, but it cannot prove the form of every possible function outside those measurements. Classify the represented data as neither of the two familiar models; do not claim the table determines a unique rule for every height.

Checklist for two reasons

1. Describe the behavior (equal differences, equal factors, or neither) using actual values, the equation, or the graph. 2. Supply a different kind of evidence: a slope, a second calculation, a matching equation form, or an explanation of why the alternative pattern fails.

Rates in exponential situations

An exponential function does not have one constant additive rate. Its numerical change per unit input depends on where you measure it, even though the multiplier over equal input steps stays constant.

Teacher's Review

The main task appropriately practices classification across representations. The following issues deserve specific clarification rather than a general criticism of the instructional approach.

Main task, Problem 14 — “each point” is not a precise growth rule

The task describes each point as one-third of the previous point, but does not identify whether the y-values are being multiplied, how the inputs progress, or what “previous” means in the graph. For a standard geometric or exponential interpretation, it must state that outputs are multiplied by one-third over equal input steps. Without that condition, classification as exponential is not established.

READY Problems 2–3 — Rate-of-change comparison is underspecified

Exponential functions have changing absolute rates, so “greater rate of change” requires a specified input interval or an indicated comparison point. Problem 3 also compares a constant weekly $25 deduction with a debt repayment that halves each week: the first changes are tied at $25 and later repayments are smaller. The question should specify the interval and whether “greater” refers to signed change or the magnitude of the decrease.

READY Problem 5 — Ambiguous Magic Pot procedure

Five pots are mentioned without specifying whether the doubling is sequential, parallel, or measured per one complete round. Consequently, the effective factor cannot be uniquely compared with without identifying the process.
