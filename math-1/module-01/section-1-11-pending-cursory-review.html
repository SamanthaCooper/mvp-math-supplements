1. In class: A Practice Understanding Task

Revisit the ideas from class

This section explains some of the ideas you explored in class through the guided exercises. Use it alongside the “A Practice Understanding Task” portion of Section 1.11 in your MVP packet.

In your MVP packetMain · 1–10 · pages 50–53
Try the packet task on your own first

Attempt the task before reading worked solutions. Use them to check your reasoning or help if you are stuck.

Connect the information you have

The task asks for at least four things about each sequence. Start by naming the input and output, then identify a difference or ratio if the information supports one. A table, a recursive rule with a starting value, an explicit rule, and a justified classification provide different useful representations.

A graph of a sequence uses separate input points. A context is optional unless requested; it should fit the mathematical rule rather than change it. The answers below are sample collections, not a unique required set.

Worked example — Main 5

Original information: The sequence is arithmetic, \(f(3)=10\), \(f(7)=26\).

Worked solution: Four steps change the output by 16, giving difference 4. Work back two steps from term 3 to term 1: \(f(1)=10-8=2\). We can now state the type, difference, initial value, and both rules:

\[f(1)=2,\quad f(n+1)=f(n)+4,\quad f(n)=2+4(n-1).\]

A table begins 2,6,10,14. Substitution at inputs 3 and 7 checks the original information.

Main 6: count the outside edges

Figure 1 has one unit-sided hexagon; figures 2 and 3 have three and five. A new hexagon shares an edge, removing that shared edge from the outside of each adjoining hexagon: it adds \(6-2=4\) to the perimeter. Each figure adds two hexagons, so perimeter increases by 8. The first perimeter is 6, giving \(P(n)=6+8(n-1)=8n-2\).

Main 9: what can actually be concluded?

The first term is −2 and the fifth is \(-1/8\), but the problem does not specify arithmetic or geometric. The total change is \(15/8\), and there are four index steps. If arithmetic is assumed, \(d=15/32\) and \(f(n)=-2+(15/32)(n-1)\). If geometric is assumed, both \(r=1/2\) and \(r=-1/2\) work, with \(f(n)=-2r^{n-1}\). These are different valid possibilities; identify any assumption used rather than claiming one unique sequence.

Main 10: read the plotted sequence

The graph includes \((0,11),(3,9),(6,7),(9,5),(12,3),(15,1)\), with the intervening whole-input points also shown. This is arithmetic: each input step decreases the output by \(2/3\). One model is:

\[f(0)=11,\quad f(n+1)=f(n)-\frac23,\quad f(n)=11-\frac23n.\]

The displayed input indices are 0 through 15. These statements, a table of the plotted pairs, and the constant difference supply at least four facts. Additional graphs not shown: the sample tables above provide points if you choose a graph as one of your representations.

In your MVP packetReady · 1 · pages 54

A sequence’s graph is not automatically the entire straight line through its points.

Check your work — Ready 1

Similarities: Arithmetic-sequence points lie on a straight line and have a constant output change per one-unit input step. Their explicit rules can be rearranged to \(y=mx+b\), with the common difference as slope.

Differences: A sequence is indexed by separate whole-number positions; a linear function commonly allows all real inputs and has a continuous line graph. Also, the first term at input 1 is generally not the y-intercept at input 0.
