Multiplying by the same factor

At time 0 there are 3 dots. Each minute, every group doubles in size: the counts are 3, 6, 12, 24, 48. This is a geometric sequence: consecutive values are multiplied by the same number, called the common ratio. Here that ratio is 2. In 1.2, we added 4 each minute; here we multiply by 2.

Time (minutes)012345
Dots3612244896

Recursive first: use the previous value

A recursive rule says how to find the next term from an earlier term. It needs a starting value. Let \(D(t)\) be the number of dots after \(t\) minutes:

\[D(0)=3,\qquad D(t+1)=2D(t),\quad t=0,1,2,\ldots.\]

Read this as “start with 3 dots; the next dot count is twice the current count.” \(D(t+1)\) is the output one minute later, not \(D(t)+1\).

Explicit: go directly to a time

An explicit rule calculates an output directly from its input. After \(t\) minutes, there have been \(t\) doublings. Repeated multiplication by 2 is \(2^t\):

\[D(t)=3\cdot2^t,\quad t=0,1,2,\ldots.\]

The coefficient 3 is the starting dot count. The base 2 is the growth factor per minute. At time 0, \(2^0=1\), so the rule gives the correct starting value 3. A nonzero number to the power 0 is 1.

Worked example — Main 2

Original problem: Find the number of dots at 5 minutes.

Worked solution: Double 48 once to get 96, or calculate \(3\cdot2^5=3\cdot32=96\). Answer: 96 dots.

Worked solution: The table puts 12 below \(n=5\). Therefore \(n-1=4\), and \(f(4)=7\). Do not subtract 1 from the output 12; \(f(n-1)\) changes the input first.

Evaluate the power before multiplying by any outside coefficient or negative sign. Parentheses change the base: \((-3)^2=9\), but \(-3^2=-(3^2)=-9\). Thus \((-3)^x\) alternates signs at whole-number inputs, while \(-3^x\) is always negative.
