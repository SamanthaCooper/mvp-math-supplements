2. Ready — Check equation solutions and complete ordered pairs

In your MVP packetSection 1.1 · Ready · 1–8 · page 3

What makes a number a solution?

A solution makes an equation true. To test a proposed solution, substitute it: replace the variable with that number, use parentheses for negative numbers, and calculate both sides. You do not need a new equation-solving method to choose among the packet’s candidates.

Worked example — Ready 2

Original problem: For \(8-2b=-2\), choose \(b=-3\), 0, or 5.

Try \(b=-3\):

\[8-2(-3)=8+6=14\]

The result is not −2, so −3 does not work.

Try \(b=0\):

\[8-2(0)=8\]

The result is not −2, so 0 does not work.

Try \(b=5\):

\[8-2(5)=8-10=-2\]

This matches the right side. Answer: \(b=5\).

Correction to the supplied example — Ready, page 3

The opening equation says \(9a+17=-21\), but the explanation switches to −19 and calls \(a=-4\) a solution. In fact, \(9(-4)+17=-19\), not −21. Read the opening equation as \(9a+17=-19\) to match the worked example. Problems 1–8 are separate from this typo.

An ordered pair records an x-value and a y-value

In \((x,y)\), the first number is the \(x\)-value and the second is the \(y\)-value. To complete a pair, substitute the given \(x\) into the equation and calculate \(y\).

Worked example — Ready 6

Use the equation \(y=-4x+9\) to complete the ordered pair when \(x=-5\).

Substitute −5 for \(x\):

\[\begin{aligned}y&=-4(-5)+9\\&=20+9\\&=29\end{aligned}\]

Write the x-value first and the y-value second:

\[\boxed{(-5,29)}\]

The order matters: \((-5,29)\) and \((29,-5)\) name different points.

Try each problem before opening the key.

Teacher/parent review of the source packet

An error in the very first Ready example — Section 1.1, page 3

The curriculum’s first lesson opens its Ready section with a worked example that contains an error. The opening equation is \(9a+17=-21\), but the explanation uses −19 and identifies \(a=-4\) as a solution. Substituting −4 gives \(9(-4)+17=-19\), so it does not satisfy the equation as written.

Changing the opening equation to \(9a+17=-19\) makes the example consistent.

The main task accepts different valid counting strategies.
