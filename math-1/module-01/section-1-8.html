Attempt the task before reading worked solutions. Use them to check your reasoning or help if you are stuck.

Choose the kind of rule before writing it

Subtract neighboring outputs. If all differences are the same, use an arithmetic rule. Otherwise check whether dividing each output by the previous nonzero output gives a constant ratio. If neither test works, do not force the table into one of those two families.

Read the starting index carefully. If the first supplied input is 0, a direct rule uses \(n\) steps from that start. If it is 1, use \(n-1\) steps. Every recursive rule needs a known initial value.

Worked example — Function A, Main 1–5

Original table: Inputs 1,2,3,4 have outputs 5,10,20,40.

Worked solution: Each output doubles. Start at \(f(1)=5\), then \(f(n+1)=2f(n)\). To reach input \(n\) there are \(n-1\) doublings, so \(f(n)=5\cdot2^{n-1}\). This is geometric; the missing fifth value is 80.

For the “find the nth term” descriptions, start with the row’s first value and apply the listed change the required number of times: \(n\) times when the first input is 0, or \(n-1\) times when it is 1.

Why Function F is neither

The outputs 3,4,7,12,19 increase by 1,3,5,7. The difference changes, and the ratio changes too. Each value is 3 more than \(n^2\), giving \(f(n)=n^2+3\). Its recursive update adds \(2n+1\) when moving from input \(n\) to \(n+1\). For example, at \(n=2\), add 5 to move from 7 to 12. This is a rule for this particular table, not an arithmetic or geometric formula.

Read a line as \(y=mx+b\)

The y-intercept \(b\) is the output where the line crosses the y-axis, at \(x=0\). The slope \(m\) is the vertical change divided by horizontal change. Choose two clear grid points, count both changes, then write \(y=mx+b\).

For example, Go 12 crosses the y-axis at 4 and the x-axis at 8. Moving right 8 drops 4, so \(m=-4/8=-1/2\). Thus \(y=-\frac12x+4\). Count the graph’s labeled units, not its physical width.
