The parent cubic

A cubic function is a degree-3 polynomial. Its simplest example, or parent function, is \(f(x)=x^3\). Cubing means multiplying three copies of the input: \((-2)^3=(-2)(-2)(-2)=-8\). Negative inputs give negative outputs, unlike squaring.

Worked solution — Main 1. The original problem asks for a table verifying a quadratic rate of change. For equally spaced inputs, subtract consecutive outputs, then repeat with the difference columns.

The first differences \(1,7,19,37\) have constant second differences, so they follow a quadratic pattern. Algebra confirms the one-step change:

\[(x+1)^3-x^3=3x^2+3x+1.\]

These are average changes over input steps of length 1. For a refresher on successive differences, see Section 3.1, a draft pending human review.

Graph and features — Main 2–3

Plot anchor points \((-2,-8),(-1,-1),(0,0),(1,1),(2,8)\), then draw a smooth increasing curve. It becomes flatter near the origin, but it keeps increasing through that point.

Main 3 answers: Domain and range are both \((-\infty,\infty)\). The x- and y-intercepts are both \((0,0)\). It increases on the entire real line, has no interval of decrease, and has no maximum or minimum. It is negative for \(x<0\) and positive for \(x>0\).

Move anchor points instead of starting over

For a refresher on shifts and vertical scaling, see Math II 2.1 — Transformers: Shifty y’s. The same point transformations apply to the cubic parent.

For \(y=a(x-h)^3+k\), each point \((u,u^3)\) on the parent moves to

\[(u+h,\;a u^3+k).\]

Move right \(h\) units (left if \(h<0\)); multiply the original y-coordinate by \(a\); then move up \(k\) units (down if \(k<0\)). A negative \(a\) reflects across the x-axis, and \(|a|\) scales the vertical distances before the vertical shift.

The horizontal shift works because \(x-h=u\) when the new input is \(x=u+h\). For example, \((x+3)^3\) uses \(h=-3\), so it shifts left 3.

Original problems — Main 4(a–d): Graph each printed rule without technology. The transformations and anchor points below give a hand-graphing method; the graphs let you check the results.

Main 4(a) — \(x^3-3\)

Worked solution: Down 3. Anchor points: \((-1,-4)\), \((0,-3)\), \((1,-2)\).

Main 4(b) — \((x+3)^3\)

Worked solution: Left 3. Anchor points: \((-4,-1)\), \((-3,0)\), \((-2,1)\).

Main 4(c) — \(2x^3\)

Worked solution: Vertical stretch by factor 2. Anchor points: \((-1,-2)\), \((0,0)\), \((1,2)\).

Main 4(d) — \(-(x-1)^3+2\)

Worked solution: Reflect across x-axis, right 1, up 2. Anchor points: \((0,3)\), \((1,2)\), \((2,1)\).

Main 5: Compare your hand-drawn graphs with technology or the checks above. Sample self-check: “I shifted left correctly in (b), but I initially forgot to reflect the y-values in (d).” Your reflection should describe your own work.

Compare the cubic with the quadratic — Main 6–7

Main 6 sample similarities: Both \(x^3\) and \(x^2\) are polynomials, are defined for every real input, are continuous, pass through \((0,0)\) and \((1,1)\), and increase for positive inputs.

Original statements and explanations — Main 7:

(a) The range of \(f(x)=x^3\) is \((-\infty,\infty)\), but the range of \(g(x)=x^2\) is \([0,\infty)\), because a cube can be negative, zero, or positive and every real number has a real cube root. A real square cannot be negative.

(b) For \(x>1\), \(f(x)>g(x)\), because \(x^3=x\cdot x^2\): multiplying positive \(x^2\) by a number greater than 1 makes it larger.

(c) For \(0<x<1\), \(g(x)>f(x)\), because multiplying positive \(x^2\) by a number between 0 and 1 makes it smaller. For example, \((\frac12)^2=\frac14\), while \((\frac12)^3=\frac18\).

2. Ready — Add and subtract binomials

In your MVP packetSection 3.2 · Ready 1–10 · printed p. 9

A binomial has two terms. Combine like terms: terms with the same variable part. For subtraction, distribute the minus sign to every term in the second parentheses.

Original worked example
\[(5x-2)-(2x+4)\]
\[=5x-2-2x-4=3x-6.\]

The \(+4\) becomes \(-4\) because the entire second expression is subtracted.

For Ready 10, add or subtract the two outputs at the same input. From the packet’s labeled lines, \(f(x)=x+2\) and \(g(x)=2x-4\). Try all exercises before checking.

4. Go — Multiply powers with the same base

In your MVP packetSection 3.2 · Go 18–20 · printed p. 12

For powers with the same base, add the exponents:

\[b^p b^q=b^{p+q}.\]

Find a common denominator before adding fractional exponents. For example, \(t^{\frac12}t^{\frac13}=t^{\frac56}\). The packet expressions have even-root denominators, so their real-number domains are \(x\ge0\), \(a\ge0\), and \(m\ge0\), respectively. Try the problems, then check.
