An identity is an equality that always works on its domain

An identity is true for every input where both sides are defined. An equation such as \(\sin\theta=1/2\) is true only at particular angles. Checking a few numbers can support a conjecture, but a proof must explain why it works for every allowed input.

The unit circle explains the fundamental identities

The point at angle \(\theta\) is \((\cos\theta,\sin\theta)\). Because the circle has radius 1, the Pythagorean theorem gives

\[\cos^2\theta+\sin^2\theta=1.\]

Here \(\sin^2\theta\) means \((\sin\theta)^2\), not \(\sin(\theta^2)\). Reflecting the point across the horizontal axis changes \(\theta\) to \(-\theta\): the horizontal coordinate stays the same, while the vertical coordinate changes sign. Thus

\[\cos(-\theta)=\cos\theta,\qquad\sin(-\theta)=-\sin\theta.\]

Reflecting across the line \(y=x\) exchanges the coordinates and changes the angle to \(\pi/2-\theta\), giving \(\sin\theta=\cos(\pi/2-\theta)\). These coordinate arguments work beyond acute right-triangle angles.

Common angle changes

AngleSineCosine
\(\pi-\theta\)\(\sin\theta\)\(-\cos\theta\)
\(\pi+\theta\)\(-\sin\theta\)\(-\cos\theta\)
\(2\pi-\theta\)\(-\sin\theta\)\(\cos\theta\)

Think of the corresponding reflections or half-turn instead of memorizing a separate unrelated rule for each row.

Worked example — Main 5b

Original problem: Prove \(\tan(\pi+\theta)=\tan\theta\).

Worked solution: Rewrite tangent as a quotient and use the half-turn coordinate changes:

\[\tan(\pi+\theta)=\frac{\sin(\pi+\theta)}{\cos(\pi+\theta)}=\frac{-\sin\theta}{-\cos\theta}=\tan\theta.\]

This proof applies where \(\cos\theta\ne0\), which is exactly where both tangent expressions are defined.

A square root needs a sign choice

If \(\sin\theta=3/4\), then \(\cos^2\theta=7/16\), so \(\cos\theta=\pm\sqrt7/4\). A quadrant or acute-angle condition is needed to select a sign. The Pythagorean identity alone cannot make that choice.
