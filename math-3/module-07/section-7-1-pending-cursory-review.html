A phase shift moves a periodic graph sideways

A periodic function repeats its outputs after a fixed interval, its period. Sine and cosine repeat every \(2\pi\) radians. A phase shift moves that repeating pattern left or right.

\[y=D+A\sin(B(t-C))\]

The midline is \(y=D\), the amplitude is \(|A|\), and the period is \(2\pi/|B|\), for \(B\ne0\). The graph shifts right by \(C\) when \(C>0\), or left by \(|C|\) when \(C<0\). The amplitude measures the distance from the midline to a peak, not the distance from bottom to top.

Worked example — Main 3 and 5: start at the top

Original problem: The wheel has radius 25 feet, center 30 feet above the ground and period 20 seconds. Write its height function when the rider starts at the top.

Worked solution: One turn is \(2\pi\) radians, so its angle increases by \(2\pi/20=\pi/10\) radians each second. Starting at the rightmost point gives

\[h(t)=30+25\sin\left(\frac{\pi}{10}t\right).\]

Starting at the top means beginning a quarter-turn ahead. Add \(\pi/2\) to the angle:

\[h(t)=30+25\sin\left(\frac{\pi}{10}t+\frac{\pi}{2}\right)=30+25\sin\left(\frac{\pi}{10}(t+5)\right).\]

The angle shift is \(\pi/2\) radians; the time shift is 5 seconds left. These are different quantities. Factoring out \(\pi/10\) makes the time shift visible. At \(t=0\), the height is 55 feet; after 5 seconds it is 30 feet. Equivalently, \(h(t)=30+25\cos(\pi t/10)\).

The noon-shadow function describes horizontal position measured from the wheel’s centerline, rather than height above the ground. For the rightmost start it is \(x(t)=25\cos(\pi t/10)\). Changing the initial position changes its phase too; it does not add the 30-foot height to a horizontal coordinate.

Main 11, page 4 — an incorrect amplitude

Both displayed equations use “50 sin” while referring back to question 5. That question still uses a radius of 25 feet. Replace 50 with 25 in both equations. The displayed expressions are equivalent to each other, but their amplitude does not describe the original wheel.

Read the maximum and minimum first: amplitude is half their difference, and the midline is their average. Measure one complete repeat for the period. Different phase shifts can describe the same graph because a whole-period shift makes no change.

Set 10, page 6 — a sign error

The first identity, \(\sin\theta=\cos(90^\circ-\theta)\), is correct. The second printed identity, \(\sin(\theta-90^\circ)=\cos\theta\), has the wrong sign. It should be \(\sin(\theta-90^\circ)=-\cos\theta\), or equivalently \(\sin(\theta+90^\circ)=\cos\theta\). For example, at \(\theta=0\), the printed version would claim \(-1=1\).
