Start with asymptotes and anchor points

Review 4.1: the reciprocal graph (draft pending human review). An anchor point is a convenient known point that helps you sketch a curve. It is not an intercept unless one coordinate is zero.

Main 1 answers: horizontal asymptote \(y=0\), vertical asymptote \(x=0\); points \((1,1),(-1,-1),(\frac12,2),(-\frac12,-2),(2,\frac12),(-2,-\frac12)\).

Move the curve by moving its inputs and outputs

Write a transformed reciprocal function as

\[y=k+\frac{b}{x-h},\qquad b\ne0.\]

Start with \(y=\frac1x\). Multiply outputs by b, then translate right h and up k. A negative h means left; a negative k means down. If b is negative, reflect across the x-axis before translating. The vertical scale factor is |b|: greater than 1 stretches, between 0 and 1 compresses.

\[(u,\tfrac1u)\longmapsto(h+u,\ k+\tfrac bu).\]

The denominator becomes zero at x=h, so the vertical asymptote is \(x=h\). At either far end, \(\frac b{x-h}\to0\), so the horizontal asymptote is \(y=k\). Inputs cannot equal h, and outputs cannot equal k. Conversely, every other output is possible: \(x=h+\frac b{y-k}\).

Main 12 featureAnswer
Vertical asymptote\(x=h\)
Horizontal asymptote\(y=k\)
Vertical stretch / reflection\(|b|\); reflect if b<0.
Anchor points\((h+1,k+b),\ (h-1,k-b)\); also \((h+\frac12,k+2b),\ (h-\frac12,k-2b)\) and \((h+2,k+\frac b2),\ (h-2,k-\frac b2)\).
Domain\(\mathbb R\setminus\{h\}\)
Range\(\mathbb R\setminus\{k\}\)

In the domain/range notation above, \(\mathbb R\) means all real numbers and \(\setminus\{h\}\) removes h from that set.

If b=0, the formula equals the constant k wherever x≠h; it no longer has the two reciprocal branches described here. The packet’s transformed reciprocal family uses b≠0.

Write a rule from a graph or description

  1. Read the vertical asymptote x=h and horizontal asymptote y=k.
  2. Use a supplied point (x,y) to solve \(b=(y-k)(x-h)\).
  3. Check the rule at the remaining marked points.
Worked solution — Main 8

Original problem: Write a rule for the supplied graph. Its asymptotes are x=5 and y=2, and its marked points are (4,5) and (6,−1).

Worked solution: substitute (4,5) into \(y=2+\frac b{x-5}\):

\[5=2+\frac b{-1}\quad\Rightarrow\quad b=-3.\]

Answer: \(y=2-\frac3{x-5}\). At x=6 it gives −1, checking the second point. The negative coefficient puts the left branch above y=2 and the right branch below it.

Sign correction — Main 6, printed p. 10

The listed point (−2,1) conflicts with the other five points. They determine \(y=\frac2x\), which gives \(y=-1\) at x=−2. Replace the point with (−2,−1). No transformed reciprocal function satisfies all the printed conditions.

Sketch by hand from the asymptotes

  1. Draw the vertical and horizontal asymptotes as dashed lines.
  2. Transform several anchor points, checking them in the rule.
  3. Draw two separate smooth branches through the points. Approach both asymptotes; do not join through the vertical asymptote.
Worked solution — Main 11, left graph

Original problem: Graph \(y=-2+\frac3{x-4}\) without using technology.

Worked solution: stretch the parent outputs by 3, shift right 4 and down 2. Draw x=4 and y=−2. Use (5,1), (3,−5), (6,−\(\frac12\)) and (2,−\(\frac72\)). The positive multiplier keeps the right branch above y=−2 and the left branch below it.
