1. In class: The graph of the reciprocal function

About the packet’s sharing example

The packet uses prize sharing to introduce \(y=1/x\), then switches what the input and output represent. Here, we’ll study the function directly through its values and graph so we can focus on how it behaves. See the note at the bottom of this lesson for more explanation.

The reciprocal function is \(f(x)=\frac1x\).

The graph below has two separate branches. Positive inputs give positive outputs, so one branch lies in Quadrant I. Negative inputs give negative outputs, so the other lies in Quadrant III. At \(x=0\), \(f(0)\) is undefined because we cannot divide by zero, so there is no point on the graph with an input of 0. Use the table to locate points on each branch.

Why does the graph get so close to the axes?

Look at the right-hand branch. As you move farther to the right, the graph gets closer and closer to the x-axis. For example, \(\frac1{10}=0.1\), \(\frac1{100}=0.01\), and \(\frac1{1000}=0.001\). The outputs get closer to 0, but never equal 0. The left-hand branch also gets closer to the x-axis as you move farther to the left.

We call the line \(y=0\), which is the x-axis, a horizontal asymptote. It tells us which horizontal line the graph gets closer to as we move far to the left or right.

Now look near the y-axis. Try positive inputs that get closer to 0:

x\(y=\frac1x\)
0.110
0.01100
0.0011000

The closer these inputs get to 0, the higher the graph climbs. On the other side, \(\frac1{-0.1}=-10\) and \(\frac1{-0.01}=-100\): the graph drops farther and farther down as negative inputs get closer to 0.

The line \(x=0\), which is the y-axis, is a vertical asymptote. As the graph gets closer to this line, it keeps climbing or dropping without stopping. There is no point on the graph at \(x=0\), because we cannot divide by 0.

What to notice on this graph

Far to the left or right, the curve gets closer and closer to the x-axis. As the right-hand branch shoots upward, it gets closer and closer to the y-axis. As the left-hand branch shoots downward, it also gets closer and closer to the y-axis. Neither branch touches either axis.

Teacher’s guide correction — Section 4.1, Question 13

Question 13 in the student packet (printed p. 4) asks students to describe the features of \(f(x)=\frac1x\), including its intervals of increase or decrease. In the MVP Secondary Math III, Module 4: Rational Expressions & Functions teacher’s guide, Section 4.1 “Winner, Winner,” the closing paragraph of “Discuss (Whole Group)” (PDF p. 12) says:

“Be sure that students can use proper notation to describe the domain and range, as well as recognizing that the function is decreasing through the entire domain.”

Why this wording is incorrect: Saying a function is decreasing over its entire domain means that whenever we choose a larger input, we get a smaller output. That fails when we compare inputs on opposite sides of 0. For example, moving from \(x=-1\) to \(x=1\) makes the output go from −1 to 1: the input increases, but the output increases too. Both inputs are in the domain, so this is a counterexample to the teacher’s guide’s statement.

Use this wording instead: “The function is decreasing on \((-\infty,0)\) and decreasing on \((0,\infty)\).” In other words, each branch goes downhill as you read it from left to right. Describe the two intervals separately because the graph has a break at \(x=0\).

4. Go — Match exponential graphs and asymptotes

In your MVP packetSection 4.1 · Go 11–18 · printed p. 7

For \(y=ab^{x-h}+k\), with \(a\ne0\), \(b>0\) and \(b\ne1\), the horizontal asymptote is \(y=k\). Changing h moves the graph horizontally; a scales or reflects it. Review Math II 3.1: exponential functions. Use an asymptote and a convenient point to distinguish the packet’s graphs, then check.

Teacher/parent review of the source packet

Teacher’s guide, Section 4.1, Question 13: The “Discuss (Whole Group)” guidance (PDF p. 12) incorrectly describes the function as decreasing through its entire domain. See the quoted passage, counterexample, and corrected wording above.

Instructional concern — Main 1–9: The sharing context may obscure the function

Equal sharing provides a starting example of \(y=1/x\), but the task introduces complications as it extends the story. In Main 6–9, the axes switch meanings: the input becomes each person’s share rather than the number of people, while the output becomes the number of people. Both relationships have the same formula, so students may miss this change.

The story also allows only whole-number people counts and corresponding shares such as \(1,\frac12,\frac13,\ldots\). Fractional people, negative inputs, and shares larger than the whole prize do not fit the situation, although the reciprocal function accepts every nonzero real input.

A real-world context is useful when it clarifies the mathematics. Here, explaining the context’s restrictions and changing quantities may distract from the function itself. This supplement therefore introduces \(y=1/x\) directly through values and its graph, allowing students to explore its behavior without first interpreting a story.
