Main 1–4: model the shared cost

Let \(n\) be the original number of people, including Amera. The $60 cost is divided equally, so the original cost per person is \(\frac{60}{n}\) dollars. With one person absent, \(n-1\) people share the cost, giving \(\frac{60}{n-1}\) dollars per person. In this context \(n\) is a whole number greater than 1.

Main 3–4 — Original problem and worked solution

Original problem: each remaining person pays $2 more. Find the original group size and explain why it makes sense.

\[\frac{60}{n-1}-\frac{60}{n}=2\]

Multiply both sides by the nonzero common denominator \(n(n-1)\):

\[60n-60(n-1)=2n(n-1)\]
\[60=2n^2-2n\quad\Longrightarrow\quad n^2-n-30=(n-6)(n+5)=0\]

Answer: \(n=6\) people originally; \(n=-5\) satisfies the algebraic equation but is impossible as a group size. With six people, each pays $10; with five people, each pays $12. The increase is exactly $2.

Solve rational equations while preserving their domain

A rational equation contains ratios of polynomial expressions. To solve, identify excluded inputs, clear denominators by multiplying every term on both sides by a nonzero common denominator, solve the polynomial equation, then check each candidate in the original equation and the context.

An extraneous solution from the algebra fails the original equation. A value can also satisfy an equation yet be rejected by a contextual restriction, such as a negative number of people or a negative completion time.

The same multiplication on both sides preserves equality at allowed inputs. You cannot simply drop the denominators of a sum: \(\frac12+\frac13=\frac56\), whereas \(1+1=2\). Also, the reciprocal of a sum is not the sum of its reciprocals.

For a refresher on factoring and common denominators, see 4.5: rational operations.

Main 5 — Original problem and worked solution
\[\frac2{x+4}-\frac1x=\frac2{3x}\]

Exclude \(x=-4,0\). The LCD is \(3x(x+4)\):

\[6x-3(x+4)=2(x+4)\quad\Longrightarrow\quad x=20\]

Check: \(\frac2{24}-\frac1{20}=\frac1{30}=\frac2{60}\). Thus \(x=20\) is the solution.

Main 7 — Original problem and worked solution
\[x+\frac{20}{x-4}=\frac{5x}{x-4}-2\]

Exclude \(x=4\). Multiply every term by \(x-4\):

\[x(x-4)+20=5x-2(x-4)\]
\[x^2-7x+12=(x-3)(x-4)=0\]

The candidates are 3 and 4. Answer: \(x=3\); both original sides equal −17. Reject 4 because the original fractions are undefined there.

2. Ready — solid measurements and right triangles

3. Set — equations and combined work rates

In your MVP packetSection 4.7 · Set 7–15 · printed pp. 49–50

For Set 7–12 use the equation-solving procedure above. Checking denominators is necessary even if a factor disappears. Try these equations before opening the key.

Add rates, not completion times

In your MVP packetSection 4.7 · Set 13–15 · printed pp. 49–50

If one worker finishes a job in \(t\) hours, the rate is \(\frac1t\) jobs per hour. With workers contributing simultaneously, add their rates. For completion time \(T\) together:

\[\frac1{t_1}+\frac1{t_2}=\frac1T\]

Keep the time units consistent and require every completion time to be positive.

Set 13 — Original problem and worked solution

Original problem: Channing needs twice Dakota’s time; together they finish in 15 hours. Find each time alone.

Let \(d\) hours be Dakota’s time; Channing’s is \(2d\).

\[\frac1d+\frac1{2d}=\frac1{15}\quad\Longrightarrow\quad\frac3{2d}=\frac1{15}\quad\Longrightarrow\quad d=\frac{45}2\]

Answer: Dakota 22.5 hours; Channing 45 hours. Check: \(\frac1{22.5}+\frac1{45}=\frac1{15}\).

Set 13–15

13: Dakota 22.5 hours, Channing 45 hours; see the worked solution.

14: let \(t\) minutes be A’s time. B takes \(t+20\) minutes:

\[\frac1t+\frac1{t+20}=\frac1{24},\qquad t>0\]
\[24(t+20)+24t=t(t+20)\quad\Longrightarrow\quad(t-40)(t+12)=0\]

Answer: A takes 40 minutes; B takes 60 minutes. Check \(\frac1{40}+\frac1{60}=\frac1{24}\). Reject \(t=-12\) because A’s time would be negative.

15: a candidate can violate the situation’s domain even when no denominator is zero. Here the second algebraic solution gives A a negative completion time. It satisfies the unrestricted rate equation, but cannot describe the machines.

Terminology clarification — Set 15, printed p. 50

The packet calls the negative time “extraneous.” More precisely, it is a valid algebraic root rejected by the context. Keep both equation checks and contextual checks.
