The square function and its parabola

In your MVP packetSection 2.1 · Main task · Problems 1–2 · p. 1

The area of a square with side length \(x\) is \(A(x)=x^2\). Since side lengths cannot be negative, this physical model has domain \(x\ge 0\). As a graphing function, however, we may use all real numbers for \(y=x^2\), including negative inputs. For example, \((-3)^2=9\), just as \(3^2=9\).

The most basic quadratic graph, \(y=x^2\), is called the parent function; its graph is a parabola. The lowest or highest point of a parabola is its vertex. A vertical line that divides it into mirror-image halves is the axis of symmetry.

\(x\)−3−2−10123
\(x^2\)9410149
Four graph features. For \(y=x^2\), the vertex is \((0,0)\), the axis of symmetry is \(x=0\), the graph opens upward, and its lowest \(y\)-value is 0 (a minimum). An \(x\)-intercept is a point where the graph meets the \(x\)-axis (\(y=0\)); the parent parabola has one, at \((0,0)\).
Worked example — read a graph from a table.

Suppose the points are \((-2,4),(-1,1),(0,0),(1,1),(2,4)\). The pair of values at \(x=-2\) and \(x=2\) match; so do those at \(-1\) and 1. The middle point \((0,0)\) is the minimum, and the vertical mirror line is \(x=0\). The graph opens upward.

Moving the whole parabola up or down

A vertical translation adds the same number to every output. Compare \(y=x^2\), \(y=x^2+3\), and \(y=x^2-2\).

For \(y=x^2+k\), a positive \(k\) shifts the graph up \(k\) units; a negative \(k\) shifts it down \(|k|\) units. The vertex is \((0,k)\) and the axis of symmetry stays \(x=0\).
Worked example — vertical shift.

Graph \(y=x^2-4\). Start with the parent points \((-2,4),(-1,1),(0,0),(1,1),(2,4)\). Subtract 4 from each output to obtain \((-2,0),(-1,-3),(0,-4),(1,-3),(2,0)\). The vertex is \((0,-4)\), the symmetry line is \(x=0\), and the graph crosses the \(x\)-axis twice.

Moving the parabola left or right

In your MVP packetSection 2.1 · Main task · Problem 6 · p. 3

Now change the input before squaring. In \(y=(x-2)^2\), the squared part is zero when \(x=2\). So the lowest point occurs at \((2,0)\): the original parabola has moved right 2. Likewise, \(y=(x+3)^2\) is zero at \(x=-3\), moving the parabola left 3.

The sign seems backward because it is the value that makes the parentheses zero—not the visible sign alone—that determines the new middle of the graph.

Input \(x\)01234
\((x-2)^2\)41014
For \(y=(x-h)^2\), the graph moves horizontally to vertex \((h,0)\) and has symmetry line \(x=h\). In particular, \((x+5)^2\) means \((x-(-5))^2\): a shift left 5.
Worked example — a horizontal table.

To graph \(y=(x+2)^2\), start with the parent points and subtract 2 from every \(x\)-coordinate: \((-4,4),(-3,1),(-2,0),(-1,1),(0,4)\). The new vertex is \((-2,0)\). This changes inputs, not outputs.

Stretching, compressing, and reflecting

In your MVP packetSection 2.1 · Main task · Problems 7–8 · p. 3

Multiplying all outputs by \(a\) gives \(y=ax^2\). If \(a=3\), each \(y\)-value triples; at \(x=1\) we move from 1 to 3. The graph is narrower (a vertical stretch). If \(a=\tfrac14\), the heights are one quarter as large, making the graph wider (a vertical compression).

If \(a\) is negative, positive heights become negative: the parabola reflects across the \(x\)-axis. Its vertex becomes a maximum rather than a minimum.

MultiplierWhat happens?
\(a>1\)Opens up; narrower than \(y=x^2\).
\(0<a<1\)Opens up; wider.
\(a=-1\)Same width; opens down.
\(a<-1\)Opens down; narrower.
\(-1<a<0\)Opens down; wider.
Worked example — negative fraction.

Compare \(y=-\tfrac12x^2\) with \(y=x^2\). At \(x=-2,-1,0,1,2\), the new outputs are \(-2,-\tfrac12,0,-\tfrac12,-2\). Since the coefficient is negative, it opens down; because its absolute value is between 0 and 1, it is wider. The vertex remains \((0,0)\), now a maximum.

Two similar-looking expressions are not equal. \(5x^2\) multiplies the area by 5, whereas \((5x)^2=25x^2\) multiplies it by 25. Always square the entire parentheses.

Connecting the changes — after learning each separately

In your MVP packetSection 2.1 · Main task · Problems 1–8 · pp. 1–3

We can now describe a parabola with a horizontal shift, a scale/reflection, and a vertical shift together:

\[y=a(x-h)^2+k\]

Start with \(y=x^2\). Move right \(h\) (or left if \(h\) is negative), multiply the vertical distances from the vertex by \(|a|\) and reflect if \(a\) is negative, then move up \(k\) (or down if negative). The vertex is \((h,k)\); the symmetry line is \(x=h\).

Worked example — two shifts and a reflection.

For \(y=-(x-1)^2+2\), first shift \(y=x^2\) right one, reflect across the \(x\)-axis, then shift up two. The vertex is \((1,2)\), the symmetry line is \(x=1\), and the vertex is a maximum. At \(x=0,2\), the height is \(-1+2=1\); at \(x=-1,3\), the height is \(-4+2=-2\). Five points are \((-1,-2),(0,1),(1,2),(2,1),(3,-2)\).

In problems 1–6, mark the vertex at the turning point, then draw the vertical axis of symmetry through it. If the vertex is \((p,q)\), the symmetry line is \(x=p\)—not \(y=q\). An upward-opening graph has a minimum; a downward-opening graph has a maximum.

Worked example — finding an exact vertex from a symmetric graph.

Imagine a graph with equal heights at \(x=1\) and \(x=5\). The symmetry line is halfway between: \(x=(1+5)/2=3\). If the lowest plotted height at that line is \(-2\), the vertex is \((3,-2)\). For a grid graph, count the squares carefully; the midpoint of equal-height points can help when the vertex falls between grid lines.

A parabola can have 0, 1, or 2 distinct \(x\)-intercepts: zero if its entire graph stays above or below the \(x\)-axis; one if its vertex touches the axis; two if the graph passes through the axis on both sides of its vertex.

Worked example — decide the intercept count without graphing.

For \(y=x^2+2\), every square is nonnegative, so \(x^2+2\) is always positive: 0 intercepts. For \(y=-x^2\), the graph touches the axis only at \(x=0\): 1 intercept. For \(y=x^2-9\), it reaches 0 at \(x=-3\) and \(x=3\): 2 intercepts.

Area models are equations drawn as regions

In your MVP packetSection 2.1 · Set · Problems 11–18 · pp. 5–6

A square with side \(x\) has area \(x^2\). Four such squares have total area \(4x^2\); a square with side \(4x\) has area \((4x)^2=16x^2\). A square with side \(x+4\) has area \((x+4)^2\). A square of area \(x^2\) together with a separate 4-unit region represents \(x^2+4\) (not necessarily a larger square).

Worked example — interpret a verbal change.

“Add 4 to the side length before finding the area” means \((x+4)^2\). “Find the area and then add 4 square units” means \(x^2+4\). The placement of parentheses records which operation happens first.

Recover an equation from a table

In your MVP packetSection 2.1 · Set · Problems 11–18 · pp. 5–6

For a vertical shift, compare each table output with the parent \(x^2\) value at the same input. The difference is constant. For a horizontal shift, find the input where the output is smallest (for upward-opening parabolas), then look for symmetric values on either side.

Worked example A — vertical shift from a table.

For inputs \(-2,-1,0,1,2\), suppose outputs are \(8,5,4,5,8\). The parent outputs would be \(4,1,0,1,4\); each has increased by 4. Therefore \(g(x)=x^2+4\), with vertex \((0,4)\).

Worked example B — horizontal shift from a table.

For inputs \(1,2,3,4,5\), suppose outputs are \(4,1,0,1,4\). The minimum 0 occurs at \(x=3\). The values mirror on either side of 3, so the function is \(g(x)=(x-3)^2\). It is the parent graph shifted right three units.

Packet clarification — 2.1, Set 13–14Two different pictures can represent an area of \(4x^2\).

The printed equations distinguish \( (4x)^2 \) from \(4x^2\). The first represents one square whose side is quadrupled (area \(16x^2\)); the second represents four original squares (area \(4x^2\). Keep the parentheses visible when matching the diagrams.

4. Go homework — simplifying square roots (19–24)

Study the worked examples first, then try the problems yourself. An answer key at the bottom of this section is provided to check your work.

In your MVP packetSection 2.1 · Go · Problems 19–24 · p. 6

This review skill is separate from graph transformations. The radical \(\sqrt{N}\) means the nonnegative square root of \(N\). In particular, \(\sqrt{49}=7\), never \(-7\), because the radical symbol chooses the principal square root.

\[\boxed{\sqrt{u^2}=|u|}\]

The absolute-value bars matter: \(\sqrt{(-5)^2}=\sqrt{25}=5=|-5|\), not \(-5\). You may remove the bars only if the quantity inside is known to be nonnegative.

Example 1 — squared sum (straightforward).

Simplify \(\sqrt{(t+6)^2}\). The squared quantity is \(u=t+6\), so \(\sqrt{(t+6)^2}=|t+6|\). If additionally \(t\ge -6\), the result is \(t+6\); otherwise retain absolute value.

Example 2 — coefficient and even powers.

Simplify \(\sqrt{64m^4n^6}\). Rewrite as \(\sqrt{(8m^2n^3)^2}=|8m^2n^3|=8m^2|n^3|=8m^2|n|^3\). We can remove the bars around \(m^2\) because a square is nonnegative.

Example 3 — a more challenging squared expression.

Simplify \(\sqrt{(7p-10)^2}\), then evaluate at \(p=1\). Symbolically the answer is \(|7p-10|\). At \(p=1\), it becomes \(|7-10|=3\). Removing the bars too early would incorrectly produce \(-3\).

Example 4 — nested products and difference.

Simplify \(\sqrt{25q^2(3r^2-s)^2}\). This is \(\sqrt{[5q(3r^2-s)]^2}=|5q(3r^2-s)|=5|q|\,|3r^2-s|\). The factors inside the bars can each be negative, so keep both unless assumptions about their signs are given.

Do not distribute square roots across addition. Usually \(\sqrt{a+b}\ne\sqrt a+\sqrt b\). For example, \(\sqrt{9+16}=5\), but \(\sqrt9+\sqrt{16}=7\). The Go problems place a square around an entire expression; treat everything inside the parentheses as one quantity.

5. Packet-specific interpretation notes

Packet clarification — 2.1, main task 1A physical side length and a mathematical input have different domains.

For the quilt's actual square side, \(x\ge0\). When the packet changes to graphing \(y=x^2\), it explicitly switches to all real-number inputs. If the side is increased by 5, physically relevant inputs remain \(x\ge0\) for the original side; this should not be confused with graphing the transformed function over all real numbers.

Packet clarification — 2.1, Set 15–18The tables are intended as transformed parent parabolas.

For these tasks, use the stated comparison with \(f(x)=x^2\) and recognize a vertical or horizontal shift. A finite table by itself does not prove that a function must follow the same equation for every input.

Teacher / parent review — material issues only

Set, 15–18: The instructions ask students to identify an equation from a finite list of values; they imply the given data arise from transformations of \(x^2\). Explicitly state this modeling assumption, because finite samples cannot establish the formula uniquely over all real numbers.

Go, 19–24: If the expected solutions simplify \(\sqrt{u^2}\) to \(u\), the packet needs a sign restriction. The mathematically correct general answer is \(|u|\), with absolute values removable only when the relevant expression is known nonnegative.
