The last lesson of the module brings earlier skills together. Rather than learning a new master formula, you will practice making precise statements about functions and choosing equations to meet given conditions.

1. How to describe a function from a graph

A function matches each allowed input with exactly one output. Read the graph from left to right. The domain is the set of horizontal coordinates that occur; the range is the set of vertical coordinates. An x-intercept occurs where the output is zero; a y-intercept occurs where the input is zero.

A maximum is the greatest output of a function on its domain, if one exists, and a minimum is the least. Report the location (input) as well as the value (output). A function is increasing when higher input values give higher outputs and decreasing when higher input values give lower outputs. State each interval in terms of x-values, not y-values.

Worked example — vertex features.

For \(q(x)=-(x-2)^2+4\), the vertex is \((2,4)\). Because the coefficient of the squared term is negative, the graph opens down. The domain is all real numbers and the range is \(( -\infty,4]\). The maximum location is \(x=2\), its value is 4, and no minimum exists. It increases on \(( -\infty,2)\) and decreases on \((2,\infty)\).

To find roots: \(0=-(x-2)^2+4\), so \((x-2)^2=4\), giving \(x=0\) and \(x=4\). Its x-intercepts are \((0,0)\) and \((4,0)\); its y-intercept is also \((0,0)\).

2. Recognize common graph families (main task Part I, 1–3)

Square-root curve

A graph with a left endpoint, then a rising curve that gradually flattens, often comes from a square root. For \(y=\sqrt{x+2}-2\), the inside quantity must be nonnegative: \(x+2\ge0\), so \(x\ge-2\). The starting point is \((-2,-2)\); the range is \([-2,\infty)\). It crosses the x-axis when \(\sqrt{x+2}=2\), or \(x=2\). At \(x=0\), the y-intercept is \(\sqrt2-2\). This function rises throughout its domain and has a minimum \(-2\) at \(x=-2\). It has no maximum.

Worked inverse — the square-root rule.

Start with \(y=\sqrt{x+2}-2\). Add 2, then square: \((y+2)^2=x+2\). Thus \(x=(y+2)^2-2\) and \(f^{-1}(x)=(x+2)^2-2\) with the inverse domain \(x\ge-2\). The inverse has range \([-2,\infty)\). Keep the restriction: without it, the whole upward parabola would include an extra branch not present in the inverse.

Exponential decay

For \(f(x)=4(\frac12)^x\), the y-intercept is 4, the graph passes through \((1,2)\), and every step right multiplies the output by \(\frac12\). Its domain is all real numbers, its range is \((0,\infty)\), and it decreases everywhere. It has neither a maximum nor a minimum; the line \(y=0\) is a horizontal asymptote, not an x-intercept.

To reverse this relationship visually, swap points such as \((0,4)\) and \((1,2)\), obtaining inverse points \((4,0)\) and \((2,1)\). An inverse equation requires logarithms, which are beyond today's algebraic requirements; the graph and swapped coordinates suffice.

Absolute-value V shape

The graph \(y=|x+2|-4\) has vertex \((-2,-4)\), domain all reals, range \([-4,\infty)\), and x-intercepts \((-6,0)\) and \((2,0)\). Its y-intercept is \((0,-2)\). It decreases for \(x<-2\), then increases for \(x>-2\). It has a minimum of \(-4\) and no maximum.

Sketching an inverse that is not a function.

Reflect each point of the V shape across \(y=x\). The original vertex \((-2,-4)\) becomes \((-4,-2)\), while the original roots \((-6,0)\) and \((2,0)\) become \((0,-6)\) and \((0,2)\). Since the resulting relation has two outputs at input 0, the unrestricted inverse is not a function. You can graph the entire inverse relation; restrict the original to one arm if asked for an inverse function.

Packet clarification — Section 4.7, Part I, 1–4.

Each graph’s axis has a one-unit scale, but the plotted curves do not consistently show endpoint dots or arrowheads. Unless your teacher specifies that the curves are restricted to the portion inside the viewing box, use the evident parent-function shapes and their natural domains for the smooth and V-shaped graphs. Do not assume a screen edge is a maximum, minimum, or included endpoint. For a piecewise graph, check whether endpoints are explicitly defined before claiming its exact domain.

3. Describe a piecewise graph (main task Part I, 4)

For a straight segment between two marked points, use \(m=(y_2-y_1)/(x_2-x_1)\), followed by \(y-y_1=m(x-x_1)\). Make a separate rule for each segment and tell which x-values use that rule. A horizontal segment has slope zero. A change from increasing to decreasing creates a local maximum; but whether it is the overall maximum depends on the entire domain.

Worked example — read and write four pieces.

In the illustrated piecewise graph, key joins are \((-2,-1)\), \((2,5)\), and \((4,1)\). A model consistent with the drawn straight pieces is

Compute the slope of each segment:

From \((-8,-4)\) to \((-2,-1)\), \(m=3/6=\frac12\), hence \(y=\frac12x\). From \((-2,-1)\) to \((2,5)\), \(m=6/4=\frac32\), hence \(y=\frac32x+2\). From \((2,5)\) to \((4,1)\), \(m=-4/2=-2\), hence \(y=-2x+9\). After x=4, the last piece stays at \(y=1\).

If these rules are continued outside the plotted view in the same way, one possible full-domain definition is:

\[f(x)=\begin{cases}\frac12x,&x<-2\\\frac32x+2,&-2\le x<2\\-2x+9,&2\le x<4\\1,&x\ge4.\end{cases}\]

The graph rises on \(( -\infty,2)\), falls on \((2,4)\), then is constant on \((4,\infty)\). The local maximum is \(5\) at \(x=2\); with the indicated first branch continued indefinitely to the left, the full function has no global minimum.

To sketch its inverse, flip the coordinates of all junctions: \((-2,-1)\to(-1,-2)\), \((2,5)\to(5,2)\), and \((4,1)\to(1,4)\). The horizontal piece \(y=1\) becomes a vertical ray \(x=1\), so the inverse relation is not a function.

Worked construction — two different functions with the same minimum.

Find two functions with minimum value 3 at x=−1. Start with a nonnegative expression that becomes zero at \(x=-1\): either \((x+1)^2\) or \(|x+1|\). Adding 3 moves the minimum to y=3. Thus \(f(x)=(x+1)^2+3\) and \(g(x)=|x+1|+3\). The first is a parabola and the second is a V shape. Both have domain all reals and range \([3,\infty)\).

Second differences: For equally spaced x-values, compute successive output changes (first differences), then differences of those changes. A quadratic \(f(x)=ax^2+bx+c\) with step size 1 has constant second difference \(2a\). A table with constant second differences supports a quadratic pattern, but finitely many data points cannot prove the rule for all real x-values.

Packet clarification — Section 4.7, Ready, problem 7.

A ray that bisects an angle must start at the angle’s vertex. The packet names ray \(\overrightarrow{AB}\) and angle \(XYZ\), whose vertex is Y, without specifying how A is related to Y. To sketch the situation as written, place A at Y (same location), let B lie inside angle XYZ, and mark \(\angle XYB\cong\angle BYZ\). A cleaner instruction would name \(\overrightarrow{YB}\) as the bisector.

7. Go — inverse functions and absolute-value pieces (21–29)

Inverses and domain restriction (21–25)

To find an inverse, write \(y=f(x)\), exchange the variables’ roles, and solve for the new output. For quadratics, the inverse relation normally has two branches, so limit the original domain to the left or right of the vertex if the inverse must be a function.

Problem A — straightforward (new).

Find the inverse of \(p(x)=5x-7\).

\[y=5x-7\quad\Rightarrow\quad y+7=5x\quad\Rightarrow\quad x=\frac{y+7}{5}.\]

Therefore \(p^{-1}(x)=\frac{x+7}{5}\). Check: \(p(3)=8\) and \(p^{-1}(8)=3\).

Problem B — more challenging (new).

Let \(q(x)=(x-4)^2+2\). Find an inverse function.

The unrestricted inverse relation is \(x=4\pm\sqrt{y-2}\), so two outputs would be possible. Choose the original domain \(x\ge4\), giving \(q^{-1}(x)=4+\sqrt{x-2}\). The inverse domain is \([2,\infty)\), range is \([4,\infty)\). Alternatively, choosing original x≤4 gives \(4-\sqrt{x-2}\).

Problem C — reversing an ordered-pair function (new).

Given \(F=\{(-1,2),(0,4),(3,7)\}\), find its inverse.

Swap coordinates in every pair: \(F^{-1}=\{(2,-1),(4,0),(7,3)\}\). Since each inverse input occurs only once, this inverse relation is also a function.

Turn absolute values into piecewise rules (26–29)

The definition \(|A|=A\) for \(A\ge0\), and \(|A|=-A\) for \(A<0\), tells you where to split the input line. First solve the inequality inside the bars, then substitute the matching signed expression.

Worked example — a linear inside expression.

For \(h(x)=|x+3|\), the sign changes at \(x=-3\).

\[h(x)=\begin{cases}-(x+3),&x<-3\\x+3,&x\ge-3.\end{cases}\]

For \(g(x)=5|x+3|\), multiply both branches by 5: \(-5(x+3)\) on x<−3 and \(5(x+3)\) on x≥−3.

Worked example — the expression changes sign twice.

Let \(f(x)=|x^2-4|+1\). The inside is negative when \(-2<x<2\) and nonnegative outside that interval. Therefore

\[f(x)=\begin{cases}x^2-3,&x\le-2\\5-x^2,&-2<x<2\\x^2-3,&x\ge2.\end{cases}\]

Check at x=0: \(|0-4|+1=5\), matching the middle branch.

Packet Go formulas at a glance.

26: split \(|x+3|\) at \(-3\). 27: split \(|x^2-4|+1\) at \(-2\) and 2. 28: split \(5|x+3|\) at \(-3\). 29: split \(|x^2-16|\) at \(-4\) and 4. For item 29 the middle rule is \(16-x^2\), and the outside rule is \(x^2-16\); include the boundary values in either adjoining equal-valued branch, but never give the same input conflicting outputs.

8. Teacher’s review

Part I, graphs 1–4: Endpoints and continuation are not fully identified by arrows or dots, despite requests for exact domain, range, and absolute extrema. Confirm whether students should infer standard full parent-function domains or restrict to the portions shown. A clearer version would use arrows or filled/open endpoints.

Ready 7: Ray AB is said to bisect angle XYZ without making A the vertex Y. State \(A=Y\) as the same plotted point or rename the ray YB.

Go 21 and 23: Quadratic inverses require restricting original domains; the instruction does correctly request restrictions when necessary. Accept either monotone branch when justified.
