You learned in 4.1 that a piecewise function uses different rules for different inputs. Today we use that idea to describe changing bicycle speeds, including how the pieces connect and how to describe their intervals precisely.

1. Review: one function with several rules

A piecewise-defined function assigns one output to each input using whichever rule applies to that input. The domain restriction printed beside each rule tells you when to use it. For example,

\[P(t)=\begin{cases}4t,&0\le t\le2\\8+2(t-2),&2<t\le5.\end{cases}\]

For \(P(1)\), use the first rule and get \(4\). For \(P(3)\), use the second rule: \(8+2(3-2)=10\). For \(P(2)\), use the first rule because it includes equality at \(t=2\).

These rules agree where the pieces join: the first reaches \(8\) at \(t=2\), and the expression for the second would also give \(8\) there. We say the graph is continuous at the join: it has no jump or hole at that point.

A function needs one output per input. Neighboring pieces may have formulas that both yield the same endpoint value, but their domain restrictions should specify unambiguously which rule owns that input. If adjacent rules gave different outputs at the same included input, the relation would not be a function.

2. Bike trips: the slope is speed

On a graph of cumulative distance traveled against time, the slope tells how fast distance is increasing. A line rising 16 miles in one hour has slope \(16\) miles per hour. A shallower line corresponds to slower riding.

In the first task, Michelle and Rashid take a four-hour ride represented by

\[f(x)=\begin{cases}16x,&0\le x\le1\\10(x-1)+16,&1<x\le2\\14(x-2)+26,&2<x\le3\\12(x-3)+40,&3<x\le4.\end{cases}\]

Here \(x\) is time in hours and \(f(x)\) is total distance in miles. Notice how each new piece starts with the total distance already traveled: \(16\), then \(26\), then \(40\).

Time intervalSpeed (slope)Distance at the end
0–1 hours16 mi/h\(f(1)=16\)
1–2 hours10 mi/h\(f(2)=10(1)+16=26\)
2–3 hours14 mi/h\(f(3)=14(1)+26=40\)
3–4 hours12 mi/h\(f(4)=12(1)+40=52\)
Worked example — reading the first ride (main task 1–6)

Fastest: the first hour, at 16 miles per hour. Slowest: the second hour, at 10 miles per hour. Domain: \([0,4]\), because the ride lasts from hour 0 through hour 4. At 2 hours: \(f(2)=26\) miles. At 3 hours: \(f(3)=40\) miles. Entire ride: \(f(4)=52\) miles.

Average rate of change

For any function, the average rate of change over \([a,b]\) is the change in the output divided by the change in input:

\[\text{Average rate of change}=\frac{f(b)-f(a)}{b-a}.\]
Worked example — changing distance

From 1 to 3 hours, the riders go from 16 miles to 40 miles. Thus their average speed over the entire two-hour interval is

\[\frac{f(3)-f(1)}{3-1}=\frac{40-16}{2}=12\text{ mi/h}.\]

That differs from either individual hourly speed because the interval spans two pieces.

3. Joining successive pieces: Rashid’s solo route

A convenient way to write a line segment with slope \(m\), starting at \((a,b)\), is \(m(x-a)+b\). When \(x=a\), the expression gives \(b\). This point-slope structure makes adjacent pieces easier to connect.

The solo-ride task provides a piecewise function in which time \(x\) is measured in minutes:

\[g(x)=\begin{cases}\frac14x,&0\le x\le20\\\frac15(x-20)+5,&20<x\le50\\\frac27(x-50)+11,&50<x\le92\\\frac18(x-a)+b,&92<x\le100.\end{cases}\]

Compare the endpoint values:

TimeCalculationCumulative distance
20 minutes\(\tfrac14(20)\)5
50 minutes\(\tfrac15(50-20)+5\)11
92 minutes\(\tfrac27(92-50)+11\)23
Worked example — finding missing numbers \(a\) and \(b\) (task 11)

The final segment starts at time 92, after Rashid has traveled 23 distance units. Match the starting point \((a,b)=(92,23)\). The last rule is therefore \(\frac18(x-92)+23\), for \(92<x\le100\). At 100 minutes it reaches \(\frac18(8)+23=24\).

Worked example — evaluating different pieces (task 10)

For \(g(30)\), use the second rule: \(\frac15(30-20)+5=7\). For \(g(64)\), use the third rule: \(\frac27(64-50)+11=15\). For \(g(10)\), use the first rule: \(\frac14(10)=2.5\). Each value represents total distance traveled after that many minutes.

The interval \([20,50]\) has average rate \((11-5)/(50-20)=\frac15\) distance units per minute. Among the solo route’s four segments, the greatest rate is \(\frac27\), on \((50,92]\).

To graph a continuous piecewise linear function, calculate its starting point and each joining point, plot them, and connect consecutive points with straight segments. Label the axes with quantities and units.

4. A piecewise function can contain a curve

Not every piece must be linear. The third task (problems 13–19) begins with a quadratic expression and then changes to two straight-line rules:

\[h(x)=\begin{cases}\frac14x^2,&0\le x\le10\\\frac12(x-10)+c,&10<x\le20\\2(x-20)+30,&20<x\le30.\end{cases}\]

Here \(x\) represents minutes and \(h(x)\) represents kilometers traveled. Its first graph piece curves upward because \(x^2\) increases faster as \(x\) increases.

Worked example — find \(c\) so the pieces connect (task 13)

At \(x=10\), the first rule reaches \(h(10)=\frac14(10)^2=25\). The second expression begins from the number \(c\) when \(x=10\), so continuity requires \(c=25\). Check the next join: at 20, the second piece gives \(\frac12(20-10)+25=30\), matching the third piece’s starting value of 30.

Worked example — evaluate and find domain and range

The domain is \([0,30]\) minutes. The output rises from 0 km to \(h(30)=2(30-20)+30=50\) km, so the range is \([0,50]\) km. To evaluate \(h(8)\), use the quadratic rule: \(\frac14(8)^2=16\) km. To evaluate \(h(15)\), use the middle rule: \(\frac12(15-10)+25=27.5\) km.

Worked example — compare five-minute average rates (task 17)

Even on the curved segment, calculate average rate by using the two endpoint values:

IntervalEndpoint calculationAverage rate (km/min)
\([0,5]\)\((6.25-0)/5\)1.25
\([5,10]\)\((25-6.25)/5\)3.75
\([10,15]\)\((27.5-25)/5\)0.5
\([25,30]\)\((50-40)/5\)2

The greatest rate is 3.75 km/min on \([5,10]\). Notice that the rate on a curved piece depends on the particular interval selected; there is no single constant slope for that piece.

Packet clarification — Section 4.2, main task 13–19. The first expression is \(\frac14x^2\), not \(\frac14x\). Its squared exponent matters: it produces the curved first segment, makes \(c=25\), and changes the rate-of-change comparison. Also, the numerical rates in this modeled story are unusually high for cycling; treat them as mathematical outputs from the specified formulas.

5. Ready homework: solving absolute value equations (1–12)

The absolute value \(|u|\) measures the distance of \(u\) from zero. A distance cannot be negative. That gives the basic rule:

If \(|u|=k\) and \(k>0\), solve both \(u=k\) and \(u=-k\). If \(k=0\), solve \(u=0\). If \(k<0\), there is no solution.

When a coefficient or constant lies outside the absolute-value bars, first isolate the absolute-value expression, then make the two cases. The bars act as grouping symbols: do not remove them before isolating.

Worked example — straightforward (new Go-style practice for Ready)

Solve \(|x-7|=4\).

Case 1: \(x-7=4\), so \(x=11\). Case 2: \(x-7=-4\), so \(x=3\). Check: both values are four units from 7.

Worked example — a coefficient and constant

Solve \(3|2x-1|-4=11\).

\[3|2x-1|=15\quad\Longrightarrow\quad |2x-1|=5.\]

Case 1: \(2x-1=5\Rightarrow x=3\). Case 2: \(2x-1=-5\Rightarrow x=-2\). Substituting either value into the original equation gives 11.

Worked example — negative coefficients and impossible answers

Solve \(-2|x+6|+1=-9\). Subtract 1, then divide by \(-2\): \(|x+6|=5\). Therefore \(x+6=5\) or \(x+6=-5\), giving \(x=-1\) or \(x=-11\).

In contrast, \(-4|x+2|=12\) becomes \(|x+2|=-3\). There is no solution, because an absolute value cannot equal \(-3\).

Packet clarification — Section 4.2, Ready 1–12. The directions say that you will have two answers, but this is not true for every absolute-value equation. An equation can have two solutions, one solution, or none. For example, the packet itself asks in problem 12 why \(|m|=-3\) has no solution; problem 8, \(|-4m|=64\), does have two.

6. Set homework: domain, range, intervals, and grading steps (13–17)

Read domain and range from a graph

The domain is the set of horizontal input coordinates used by a graph. The range is the set of vertical output coordinates. Interval notation uses square brackets for included endpoints and parentheses for excluded endpoints:

InequalityInterval notationMeaning
\(-2\le x\le5\)\([-2,5]\)Both endpoints included
\(-2<x\le5\)\((-2,5]\)Left excluded, right included
\(-2\le x<5\)\([-2,5)\)Left included, right excluded

For a connected graph, identify the leftmost and rightmost inputs for the domain and the lowest and highest outputs for the range. For a graph containing gaps, write the union of separate intervals as needed.

Worked example — read a multi-segment graph

Suppose a connected graph runs from the filled point \((-3,4)\) down to \((0,-1)\), up to \((4,2)\), and finishes at the filled point \((6,1)\). Its domain is \([-3,6]\); its range is \([-1,4]\). The graph’s changing direction does not change this method.

Write a domain for each piece

To separate a graph into three adjacent pieces with change points at \(x=0\) and \(x=4\), one possible partition is:

\[-3\le x<0,\qquad 0\le x<4,\qquad4\le x\le6.\]

Together, these intervals cover \([-3,6]\), and they do not assign a shared boundary to more than one rule. You could choose the ownership of a joining point differently if the formulas agree and the graph is unchanged; always match the graph’s open and filled circles when those are shown.

Worked example — nonconnected graph

A graph exists for \(-5\le x<-1\) and \(2\le x\le6\), with no points between \(-1\) and 2. Its domain is \([-5,-1)\cup[2,6]\), not \([-5,6]\). The union symbol \(\cup\) combines the two permitted input intervals.

Step functions: letter grades

A step function is piecewise constant: its output stays at one level over an interval, then jumps to another level. Letter grades are one example: every test score in a particular percentage band receives the same letter.

Worked example — a grading policy (modeled on Set 17)

Under this example grading scale for scores \(0\le x\le100\), let \(G(x)\) be the letter grade:

\[G(x)=\begin{cases}\mathrm{F},&0\le x<60\\\mathrm{D},&60\le x<70\\\mathrm{C},&70\le x<80\\\mathrm{B},&80\le x<90\\\mathrm{A},&90\le x\le100.\end{cases}\]

Thus \(G(79)=\mathrm C\), but \(G(80)=\mathrm B\). The graph has five horizontal pieces and jumps at 60, 70, 80, and 90. This scale is an illustrative convention; use the intervals shown in the packet’s graph to complete its own blanks.

Packet clarification — Section 4.2, Set 17. The grade graph’s horizontal axis has no explicit percentage scale in the printed figure. Accordingly the exact numerical grade cutoffs cannot be read uniquely from the graphic alone unless the reader supplies a grading convention (or a teacher specifies the tick values). The example 60/70/80/90 cutoffs above is a common convention, not a value established by the packet image.
Packet clarification — Section 4.2, Set 15–16. At a shared endpoint where the two graph pieces meet, the two formulas can have the same value. It is helpful to assign the boundary input to just one expression when recording intervals, as in the packet’s example, though the graph alone may not determine which of the adjacent expressions owns that boundary unless an open or filled endpoint is indicated.

8. Teacher’s review (teacher/parent reference)

Main task, problems 13–19: The formula \(h(x)=\frac14x^2\) produces a curved segment with unusually large numeric cycling distances in the given units (25 km after 10 minutes and 50 km after 30 minutes). It is internally consistent but not realistic for a human cyclist; explicitly distinguish the exercise’s mathematical model from practical cycling speeds.

Ready instructions, problems 1–12: The statement “You will have two answers” is inconsistent with problem 12, which intentionally has no solution. Suggested revision: “Find all real solutions; some equations may have no solution.”

Set 17: The printed grading-step graph does not sufficiently label the horizontal scale to uniquely determine exact score cutoffs. Provide the intended percentage thresholds in the text or label the graph’s x-axis.
