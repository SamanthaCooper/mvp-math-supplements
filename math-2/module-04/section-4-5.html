1. Rate: miles per hour and minutes per mile

In your MVP packetSection 4.5 · Main task · Problems 1–8 · pp. 22–23

A rate compares two changing quantities. When the units are reversed, the numerical rate also changes. Chandler bikes 12 miles per hour. This is the same as one mile every five minutes, because \(60\div12=5\).

If \(t\) is elapsed time in minutes and \(d\) is distance in miles, Chandler’s distance rule is

\[d=\frac{12}{60}t=\frac{t}{5}.\]
Worked example 1 — Read and build a table.

For \(t=0,5,15,30,60\) minutes, multiply by \(\frac15\).

Time \(t\), minutes05153060
Distance \(d\), miles013612

After 30 minutes, \(d(30)=30/5=6\) miles. On a graph of distance against time, the slope is \(1/5\) mile per minute.

Isaac says he takes five minutes to bike each mile. If the input is distance \(d\) and the output is time \(t\), Isaac’s rule is \(t=5d\). That means 6 miles take \(5(6)=30\) minutes. There is no speed difference: Chandler and Isaac both travel 12 mph.

Worked example 2 — Change the roles of the variables.

In the first rule, \(t=15\) minutes gives \(d=3\) miles. In the reversed rule, \(d=3\) miles gives \(t=15\) minutes. The input and output trade roles:

Distance from timeTime from distance
Input 15 min → Output 3 milesInput 3 miles → Output 15 min
\((15,3)\)\((3,15)\)

2. What makes two functions inverses?

In your MVP packetSection 4.5 · Main task · Problems 1–8 · pp. 22–23

A function takes an input and produces an output. Its inverse reverses that correspondence: it takes the old output and returns the old input. The inverse of \(f\) is written \(f^{-1}\), pronounced “f inverse.” The \(-1\) is not an exponent here; it does not mean \(1/f(x)\).

Inverse pairs: If \(f(a)=b\), then \(f^{-1}(b)=a\). On a table or list of ordered pairs, switch the coordinates in each pair: \((a,b)\longleftrightarrow(b,a)\).
Worked example 3 — Invert a table.
Input to \(f\)−403
Output of \(f\)72−1
Input to \(f^{-1}\)72−1
Output of \(f^{-1}\)−403

Since \(f(3)=-1\), we know \(f^{-1}(-1)=3\).

For our biking rules, \(f(t)=t/5\) returns distance in miles. Its inverse \(f^{-1}(d)=5d\) returns minutes. An input of 6 now means six miles, not six minutes. Interchanging the axes’ units is an essential part of interpreting the inverse correctly.

Worked example 4 — Reverse a linear equation.

Suppose \(f(x)=2x+3\). Begin with \(y=2x+3\), exchange the input and output letters, and then isolate the new output:

\[x=2y+3\quad\Longrightarrow\quad x-3=2y\quad\Longrightarrow\quad y=\frac{x-3}{2}.\]

Thus \(f^{-1}(x)=(x-3)/2\). Check a pair: \(f(4)=11\), and \(f^{-1}(11)=4\). We are simply undoing “multiply by two, then add three” in reverse order.

3. Graphing an inverse and the function test

In your MVP packetSection 4.5 · Main task · Problems 1–8 · pp. 22–23

On a coordinate plane, reversing the coordinates turns \((a,b)\) into \((b,a)\). This is a reflection across \(y=x\). To graph an inverse, identify important points, switch each point’s coordinates, and connect the reflected points in the matching order and shape.

Does the inverse always pass the function test? No. An ordinary function assigns exactly one output to each input. For its inverse also to be a function, the original must never assign the same output to two different inputs. Such a function is called one-to-one. Graphically, its horizontal lines meet the original graph at most once: the horizontal line test.

Worked example 5 — Why an inverse can fail.

Imagine \(f\) contains \((1,4)\) and \((3,4)\). It is allowed for two different inputs to have the same output in an ordinary function. But the inverse relation contains \((4,1)\) and \((4,3)\). Now input 4 produces two outputs, so the inverse is not a function.

The vertical line test checks whether the original graph is a function. The horizontal line test checks whether its inverse will be a function. The inverse relation can always be drawn by exchanging coordinates, even if it cannot be represented by one output for every input.

4. Ready (problems 1–7): square roots and square areas

In your MVP packetSection 4.5 · Ready · Problems 1–7 · p. 24

A square with side length \(s\) has area \(A=s^2\). Since physical lengths are nonnegative, the side length is \(s=\sqrt A\), the principal (nonnegative) square root. For example, 49 square centimeters of area means a side length of 7 cm.

Worked example 6 — Perfect-square expression.

If the area is \((x-8)^2\) square feet, then the side length is

\[\sqrt{(x-8)^2}=|x-8|\text{ ft}.\]

The absolute value is necessary: \(\sqrt{z^2}=|z|\), not always \(z\). If the problem additionally says that the side length is exactly \(x-8\) feet, then \(x-8\ge0\), so \(x\ge8\).

Worked example 7 — Recognize a perfect square trinomial.

Find the side length when \(A=9x^2+30x+25\) square inches:

\[9x^2+30x+25=(3x+5)^2,\qquad s=|3x+5|\text{ in}.\]

First and last terms are squares, and the middle term equals \(2(3x)(5)=30x\).

In the tables of \(f(x)=\sqrt{x}\), distinguish these situations:

Input formHow to simplifyExample
Perfect-square numberTake its nonnegative square root\(\sqrt{81}=9\)
Number with a square factorPull out the largest square factor\(\sqrt{72}=\sqrt{36\cdot2}=6\sqrt2\)
Perfect-square expressionRecognize \((x-a)^2\)\(\sqrt{x^2-12x+36}=|x-6|\)
Packet clarification — 4.5 Ready, problems 2, 3, and 7.

The area expressions contain unknown variables. A square's side is the nonnegative root of its area, so \(\sqrt{(x-11)^2}=|x-11|\), \(\sqrt{(5a+6)^2}=|5a+6|\), and \(\sqrt{x^2-2kx+k^2}=|x-k|\). Replacing these by \(x-11\), \(5a+6\), or \(x-k\) requires knowing those expressions are nonnegative.

5. Set (problems 8–14): apply inverse ideas

In your MVP packetSection 4.5 · Set · Problems 8–14 · pp. 25–26

Problem 8 — Ordered pairs. If a relation contains \((-13,5)\), its inverse contains \((5,-13)\). Reverse every pair, including pairs containing zero or negative numbers. To determine whether the reversed relation is a function, check whether the original list has duplicate output values.

Problems 9–10 — A piecewise graph. The packet’s graph descends and then rises; some horizontal lines intersect it twice. The reflected relation will have a section that doubles back sideways. Therefore its inverse graph does not pass the vertical line test.

Problem 11 — The suitcase story. Packing something last means it is near the top and available to remove first. The order of operations reverses, just as inverse functions undo steps in the reverse order. This analogy helps explain inverses but does not by itself establish whether an inverse is a function.

Problems 12–14 — Table and reflection. The packet table shows \((-10,-2),(-6,-1),(-2,0),(2,1),(6,2)\). Its inverse points are \((-2,-10),(-1,-6),(0,-2),(1,2),(2,6)\). Each original output appears only once, so the inverse of this finite table is also a function. Reflect these points over \(y=x\) on the provided grid.

Packet clarification — 4.5 Set, problems 9–10 and 12–14.

In problems 9–10, graph the inverse relation even though it is not itself a function. Problem 14 asks about the inverse of the tabulated points in problem 12; that finite inverse does pass the function test. A table alone does not determine a unique rule for values between its listed inputs.

6. Go (problems 15–20): multiplying radical expressions

In your MVP packetSection 4.5 · Go · Problems 15–20 · p. 26

Use the distributive property and the product rule for nonnegative radicands: \(\sqrt a\sqrt b=\sqrt{ab}\). In particular, \((\sqrt a)^2=a\). Combine like radicals only after simplifying their radicands.

Problem A — Straightforward (original).

Multiply \(\sqrt5(4+3\sqrt5)\).

\[\sqrt5(4+3\sqrt5)=4\sqrt5+3(\sqrt5)^2=4\sqrt5+15.\]

We distributed first, then replaced \((\sqrt5)^2\) by 5.

Problem B — More challenging (original).

Multiply \((2+\sqrt7)(3-2\sqrt7)\).

\[\begin{aligned}(2+\sqrt7)(3-2\sqrt7)&=6-4\sqrt7+3\sqrt7-2(7)\\&=-8-\sqrt7.\end{aligned}\]

Every term in the first binomial must multiply every term in the second. Then combine like radical terms.

Problem C — Conjugates (original).

Multiply \((5+3\sqrt2)(5-3\sqrt2)\).

\[\begin{aligned}(5+3\sqrt2)(5-3\sqrt2)&=25-15\sqrt2+15\sqrt2-9(2)\\&=25-18=7.\end{aligned}\]

The radical terms cancel. More generally, \((a+b)(a-b)=a^2-b^2\); these are called conjugate binomials.

Problem D — Two radicals with unlike coefficients (original).

Multiply \((3-2\sqrt3)(4+5\sqrt3)\).

\[\begin{aligned}(3-2\sqrt3)(4+5\sqrt3)&=12+15\sqrt3-8\sqrt3-10(3)\\&=-18+7\sqrt3.\end{aligned}\]

Remember: \(\sqrt3\cdot\sqrt3=3\), but \(\sqrt3\) and a plain number are not like terms.

8. Teacher’s review (for teachers and parents)

Main task, problems 5–8 — Critical distinction. Chandler and Isaac describe the same speed (12 mph = 5 min/mile), not two different travel behaviors. Their descriptions become inverse functions only if one chooses minutes → miles and the other chooses miles → minutes. If both are modeled as distance as a function of time, they are the same function. Clarify the choice of inputs and outputs before stating they are inverse.

Set, problems 9–10 — Inverse relation versus inverse function. The inverse of the graphed V-like piecewise function fails the vertical line test. Problem 9’s request to “graph \(f^{-1}(x)\)” may imply a function exists. Clearer wording: “Reflect the graph across \(y=x\) to graph the inverse relation. Determine whether that relation is a function.”

Ready, problems 2, 3, 7 — Principal square root. For variable inputs, the square root of a squared expression is its absolute value. State any needed nonnegativity restrictions rather than automatically dropping absolute value signs.
