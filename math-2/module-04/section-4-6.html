In Section 4.5, you learned that inverse relationships reverse inputs and outputs. Today you will write the rules yourself, use them in a practical situation, and decide when an inverse is actually a function.

1. Reversing an input–output relationship

In your MVP packetSection 4.6 · Main task · Problems 1–11 · pp. 27–29

Imagine a machine that takes a number, doubles it, and adds 5. An input of 3 produces 11. To run the relationship backward, start with 11, subtract 5, and divide by 2. The result is 3.

Undo operations in reverse order. If the original rule is \(f(x)=2x+5\), then \(y=2x+5\), so \(y-5=2x\) and \(x=(y-5)/2\). The inverse rule is \(f^{-1}(x)=\frac{x-5}{2}\). The superscript \(-1\) indicates an inverse function, not a reciprocal.

A function’s domain (allowed inputs) becomes its inverse’s range (outputs), and vice versa. If both are functions, their graphs mirror each other across \(y=x\).

2. Bernie’s signs: a table, a formula, and its inverse

In your MVP packetSection 4.6 · Main task · Problems 1–11 · pp. 27–29

Ink required by sign length — task problems 1–3

In your MVP packetSection 4.6 · Main task · Problems 1–11 · pp. 27–29

The packet records sign lengths of 3, 4, 2, and 15 feet with corresponding ink quantities of 9, 16, 4, and 225 ounces. Every output is the square of the input, suggesting the model \(I(L)=L^2\).

Sign length \(L\) (feet)23415\(L\)
Ink \(I(L)\) (ounces)4916225\(L^2\)

Because sign lengths are nonnegative, the physically meaningful domain is \([0,\infty)\), and the range is \([0,\infty)\). The equation \(I(L)=L^2\) models the supplied table; the numerical coefficient carries the necessary units of ounces per square foot.

Worked example — reverse the ink rule.

If Bernie uses 49 ounces of ink, what sign length does the model predict?

Start with \(I=L^2\). Since a sign’s length is nonnegative, \(L=\sqrt{I}\). Thus \(L=\sqrt{49}=7\) feet.

The inverse model is \(I^{-1}(z)=\sqrt z\), where \(z\) represents ounces of ink. Its domain and range are both \([0,\infty)\). Notice how the units and roles switch: ink in, length out.

Two operations: height from length — task problems 4–7

In your MVP packetSection 4.6 · Main task · Problems 1–11 · pp. 27–29

Bernie specifies that a sign’s vertical height is 5 inches more than twice its horizontal length. Both columns of the packet’s table, however, are labeled in feet. We will first make the units consistent.

Five inches equals \(\frac5{12}\) feet. For horizontal length \(L\) feet, the height in feet is therefore

\[H(L)=2L+\frac5{12}.\]
Length, feet23415
Height, feet\(4\frac5{12}\)\(6\frac5{12}\)\(8\frac5{12}\)\(30\frac5{12}\)

For nonnegative length, the domain is \([0,\infty)\), and the height range is \([\frac5{12},\infty)\). The inverse takes height in feet as its input. Undo the addition first and doubling second:

Worked example — find the inverse height rule.\[y=2L+\frac5{12}\]\[y-\frac5{12}=2L\]\[L=\frac{y-\frac5{12}}2=\frac y2-\frac5{24}.\]

Thus \(H^{-1}(y)=\frac{y-5/12}{2}\). Its domain is \([\frac5{12},\infty)\), and its range is \([0,\infty)\). For a height of \(8\frac5{12}\) feet, the inverse gives a 4-foot horizontal length.

Packet clarification — Section 4.6, task problems 4–7.

The printed rule says “5 inches more,” while the table measures length and height in feet. The mathematically consistent feet-to-feet rule is \(H(L)=2L+5/12\), not \(2L+5\). The wording of problem 6 (“adding 5”) suggests that the exercise may have intended the table to use inches or the verbal rule to say 5 feet. If your teacher directs the latter interpretation, use \(H(L)=2L+5\), with inverse \((y-5)/2\), and adjust the table accordingly.

3. Finding inverse rules algebraically

In your MVP packetSection 4.6 · Main task · Problems 1–11 · pp. 27–29

For an inverse, interchange which quantity is known and which is sought. A reliable procedure is to write \(y=f(x)\), solve for \(x\), then express the result using the input letter of the inverse. The inverse may require a domain restriction.

Worked example — linear function (task 9).

Given \(g(x)=3x+2\), reverse the two operations:

\[y=3x+2\quad\Rightarrow\quad y-2=3x\quad\Rightarrow\quad x=\frac{y-2}{3}.\]

Therefore \(g^{-1}(x)=(x-2)/3\). Both functions have domain and range all real numbers. Check: \(g(4)=14\) and \(g^{-1}(14)=4\).

Worked example — squared input (task 8).

Consider \(f(x)=x^2-1\), with all real inputs. Solving \(y=x^2-1\) gives \(x=\pm\sqrt{y+1}\). Each input above \(-1\) has two inverse outputs, so this inverse relation is not a function on the original domain.

To make an inverse function, restrict the original domain to \(x\ge0\). Now \(f^{-1}(x)=\sqrt{x+1}\), with inverse domain \([-1,\infty)\) and range \([0,\infty)\). Or restrict the original to \(x\le0\), obtaining \(-\sqrt{x+1}\) instead.

Worked example — shifted parabola (task 10).

For \(f(x)=(x+3)^2\), first solve \(y=(x+3)^2\):

\[x+3=\pm\sqrt y\quad\Rightarrow\quad x=-3\pm\sqrt y.\]

The full inverse relation has two branches; it is not a function if the original domain is all reals. Restrict the original domain to \([-3,\infty)\) to obtain \(f^{-1}(x)=-3+\sqrt x\), whose domain is \([0,\infty)\) and range is \([-3,\infty)\). The other restriction, \(( -\infty,-3]\), gives \(-3-\sqrt x\).

Worked example — a cube (task 11).

For \(f(x)=x^3\), every output comes from exactly one real input. Therefore:

\[y=x^3\quad\Rightarrow\quad x=\sqrt[3]{y}\quad\Rightarrow\quad f^{-1}(x)=\sqrt[3]{x}.\]

Both original and inverse have domain and range \(( -\infty,\infty)\). A cube root can be negative, unlike the principal square root.

4. Ready — classify functions from their graphs (1–6)

In your MVP packetSection 4.6 · Ready · Problems 1–6 · pp. 30–31

Ready asks you to find each function’s domain and range and classify its graph. Read the actual endpoints, gaps, and direction of the graph; do not assume all curves extend forever.

FeatureHow to identify it
Domain / rangeList all x-values / y-values shown; use brackets for included endpoints and parentheses for excluded endpoints or infinities.
DiscreteOnly isolated points are defined, often at whole-number inputs.
ContinuousThe curve can be traced without lifting your pencil over the stated interval.
DiscontinuousIt has a gap, jump, hole, or break.
Increasing / decreasing / constantAs you move to the right, outputs go up / down / stay level. A graph can have different behaviors on different intervals.
Worked example — classify a graph from coordinates.

Suppose a graph consists of a filled straight segment from \((-2,1)\) to \((3,6)\). Its domain is \([-2,3]\), its range is \([1,6]\); it is continuous and increasing. If the segment were replaced by just those two isolated points, its domain would be \(\{-2,3\}\), its range \(\{1,6\}\), and it would be discrete.

5. Set — square-root speed and stopping distance (7–10)

In your MVP packetSection 4.6 · Set · Problems 7–10 · p. 32

The packet gives a model relating stopping distance \(d\), in feet, to speed \(s\), in miles per hour:

\[s(d)=\sqrt{30d},\qquad d\ge0.\]

Square roots use the nonnegative root here because speed is not negative. The inverse equation follows by squaring both sides and dividing by 30:

\[s^2=30d\quad\Rightarrow\quad d(s)=\frac{s^2}{30},\qquad s\ge0.\]

This is a mathematical model for the exercise, not a universal stopping-distance law. Actual stopping depends on conditions and response time.

Worked example — the accident investigation (problem 8).

Skid marks are 150 feet long. The model predicts \(s(150)=\sqrt{30\cdot150}=\sqrt{4500}=30\sqrt5\approx67.1\) mph. Under this model, the driver’s statement that the speed was below 60 mph is not supported.

To check: at 60 mph, the predicted distance would be \(d(60)=60^2/30=120\) feet, less than 150.

To complete problems 9–10, put speed on the horizontal axis and stopping distance on the vertical axis for the inverse graph. The two graphs use exchanged coordinates, and when drawn on identically scaled axes their points are reflections across \(y=x\).

6. Go — solve literal equations (11–16)

In your MVP packetSection 4.6 · Go · Problems 11–16 · p. 33

A literal equation uses several letters, with each letter standing for a quantity. “Solve for \(r\)” means isolate \(r\), leaving the other letters in the expression.

Procedure. Undo addition/subtraction, multiplication/division, and powers in the appropriate order. When solving a geometric formula involving a length, select the nonnegative root. State any necessary condition, such as a nonzero denominator.
Problem A — straightforward (new).

Solve \(P=2a+2b\) for \(a\).

\[P-2b=2a\quad\Rightarrow\quad \boxed{a=\frac{P-2b}{2}=\frac P2-b}.\]

First subtract the term without \(a\), then divide by its coefficient.

Problem B — more challenging (new).

Solve \(V=\pi r^2h\) for \(r\), assuming \(V\ge0\), \(h>0\), and \(r\ge0\).

\[\frac{V}{\pi h}=r^2\quad\Rightarrow\quad\boxed{r=\sqrt{\frac{V}{\pi h}}}.\]

Divide by the factors multiplying \(r^2\), then take the nonnegative square root because a radius cannot be negative.

Problem C — solving a trapezoid formula (new).

Given \(A=\frac{(b_1+b_2)h}{2}\), solve for \(b_2\), with \(h\ne0\).

\[2A=(b_1+b_2)h\]\[\frac{2A}{h}=b_1+b_2\]\[\boxed{b_2=\frac{2A}{h}-b_1}.\]

Reversing operations is useful for literal equations just as it is for inverse functions.

Other forms required in the packet.

For problem 11, \(C=2\pi r\) gives \(r=C/(2\pi)\). For problem 12, \(A=\pi r^2\) gives \(r=\sqrt{A/\pi}\). For problem 13, \(V=\pi r^2h\) gives \(h=V/(\pi r^2)\) when \(r\ne0\). For problem 15, \(V=e^3\) gives \(e=\sqrt[3]{V}\). For problem 16, \(A=\frac{b_1+b_2}{2}h\) gives \(h=\frac{2A}{b_1+b_2}\), provided \(b_1+b_2\ne0\).

8. Teacher’s review

Significant issue — main task, problems 4–7: The verbal rule adds five inches to twice a length given in feet, while the table labels the output in feet. Problem 6 then says “adding 5,” without a unit conversion. Recommend making both units inches, changing the addition to five feet, or explicitly instructing students to add \(5/12\) feet.

Important missing restriction — main task, problems 8 and 10: The inverse of an unrestricted quadratic is a two-branch relation, not a function. The task asks for \(f^{-1}(x)\) without specifying a branch/domain restriction. Recommend adding \(x\ge0\) to problem 8 and \(x\ge-3\) to problem 10, or explicitly requesting the inverse relation instead.

Minor wording and labeling: The main task’s header reads “Secondary Math I” while the module and homework are Secondary Math II. The mathematics in this supplement follows the course and module designation.
